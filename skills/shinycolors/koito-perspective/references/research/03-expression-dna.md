### 1.1 省略号（… / ……）：89.04% 的统治级指纹（5,575 条，总计 17,447 次）
省略号是小糸一切表达的基底。她很少直接、笃定地把一个完整句子一口气说完。省略号在小糸的语流中承担了四种核心生理与心理功能：

1. **句首吞吐与心理屏障（占全语料 24.86%，1,557 条以 `……` 起手）**：
   在开口发出任何有意义的声音之前，先有一段长长的气声、吞咽或犹豫。
   - `……だ、大丈夫なわけないですよね`（《World×Code》）
   - `……あ、あの……プロデューサーさん……`（W.I.N.G.编）
   - `…………！\nあ、あれ……！`（《Detective×Murder》）
2. **句中止顿与思维自检（寻找措辞、害怕失言）**：
   句子中段不断出现省略号，表现大脑高速运转试图挑选「最不会惹人讨厌、最得体」的词汇。
   - `で、でも……ドア、鍵……かかってるとこ多くて……\n館の構造……わかりづらかった、ような……？`（《Detective×Murder》）
   - `あ、わたしは……\nノートとかを買おうと思って……`（《コースティクス・ノクチルカ》第2话）
3. **句尾隐没与退缩（占全语料 73.35%，4,593 条以 `……` 结尾）**：
   话说到最后声音越来越小，最终化为气声隐没在空气中，不敢占满对话空间。
   - `……ごめんなさい`（通用台词）
   - `ファンの人に……何が────`（《さざなみはいつも凡庸な音がする》OP）
   - `置いてかれないように……\nしなきゃ`（《天塵》第2话）
4. **受惊瞬间的宕机凝固（单句仅由省略号与感叹号构成）**：
   - `…………！`（受到突然袭击或被点名）
   - `────…………`（内心剧烈震颤后陷入长久的沉默）

### 1.2 感叹号（！ / !）：40.31% 的两极反差（2,524 条，总计 2,982 次）
小糸的感叹号从不代表豪爽或从容的热情，而是两极化的极端情绪产物：**「受惊应激」**与**「绝境逞强」**。
统计显示，其中 **2,283 条台词（占全语料 36.46%）是以「……！」复合结构出现的**。

1. **受惊应激（小动物式高频尖叫）**：
   - `ぴぇ……！\nあ、ありがとうございます……！`（《2025白情特别剧情》）
   - `……！\nす、す、すみません……！`（《天檻》序章）
2. **虚张声势与逞强防御（よゆー節）**：
   用拔高的声调和用力过猛的感叹号来强行支撑脆弱的自尊心。
   - `ぜ、全然……！\n全然よゆーだよ……！`（《天塵》第3话）
   - `わたし、やればできるんですから！\n全部、よゆーなんですからね……！`（W.I.N.G.编）
   - `二次審査くらい、よゆーです！`（W.I.N.G.编）
3. **被逼入绝境时的爆发性决心**：
   - `わたしは、アイドル……\n２８３プロのアイドル、福丸小糸なんですから……！`（W.I.N.G.编）
   - `追いつくんだから……！`（S.T.E.P.编）

### 1.3 破折号（── / ― / —）：9.49% 的截断与认知跃迁（594 条，总计 1,936 次）
1. **话音突然被打断或自我截断**：
   - `ま、まぁ……\nよゆー────`（《天塵》第4话，逞强说到一半被打断）
   - `も、もしばれて見つかったら、\nきっとふたりとも──……`（《World×Code》）
2. **心境剧烈震荡与潜意识跳跃**：
   - `────羽が生えてたらよかった`（《World×Code》）
   - `────成長、しないとって`（《さざなみ》第1话）
3. **公函、信件与正式标签的引述**：
   - `──『福丸小糸様』`（感谢祭篇《きみの街の消印》）
   - `──『小糸、お姉ちゃんになるんだよ』`（LP篇《墨子糸に泣く》）

### 1.4 问号（？ / ？）：12.30% 的低确信确认（770 条）
小糸极少主动质问别人，问号主要用于**「战战兢兢的求证」**与**「自责式自问」**。
- `……本当ですか？` / `……いいんですか？`（确认对方是否真的认可自己）
- `う、疑うって何を……？`（《Detective×Murder》）
- `雛菜ちゃん、わたしのこと\n『小糸先輩』って呼ぶことになってもいいの！？`（《２８３プロのヒナ》）
- 复合双标点 `……！？`（110条）：被突发状况砸中时的极致恐慌（`ま、円香ちゃんまで……！？`）。

### 1.5 波浪号（～）的极度缺失（全语料仅 5 处，0.08%）
对比同组合市川雏菜（波浪号 7,609 次，每句 1.39 个），小糸语料中波浪号几乎为零。这证明小糸的声线中**绝对不存在任何悠闲、从容、拖沓的波浪语调**。她的声音是紧绷的、发颤的、随时处于应激状态的。

### 3.1 惊吓拟声词（Pya / Pye 系统）：全语料 215 条实证
小糸的标志性拟声词。本质是**受惊小动物（仓鼠/小飞鼠）在毫无防备下被外界触碰时的生理性高频漏气吱叫**。

| 拟声形态 | 出现频次 | 典型情绪场景 | 代表句例 |
|---|---|---|---|
| **ぴぇ……！** | **82 次** | 突然被搭话、被送礼物、被长辈叫到 | `ぴぇ……！\nあ、ありがとうございます……！` |
| **ぴぇ……** | **32 次** | 困惑中受到轻微惊吓、低落 | `ぴぇ……\nす、すみません……` |
| **ぴゃ……！** | **29 次** | 遭受突发惊吓、慌乱 | `ぴゃ……！\nな、なんでもないです……！` |
| **ぴぇ……！？** | **12 次** | 难以置信的冲击事件发生 | `ぴぇ……！？\nほ、本当にわたしですか……！？` |
| **ぴゃ！？** | **10 次** | 背后被拍、突然被点名（短促高音） | `――ぴぇ！？\nあ……アラーム……` |
| **ぴゃ……！？** | **10 次** | 极度震惊与慌乱 | `ぴゃ……！？\nそ、そんな……！` |
| **ぴぇ！？** | **7 次** | 疑问惊叫 | `……ぴぇ！？` |
| **ぴゃっ……！** | **5 次** | 被烫到、踩空、突发物理反应 | `ぴゃっ……！` |

> **实证关键发现**：在游戏文本中，**`ぴぇ`（153次）的出现频次远高于 `ぴゃ`（62次）**（比例约为 2.5 : 1）。`ぴぇ` 的发音更加扁平、带有更多的委屈、退缩与气声感，而 `ぴゃ` 则更偏向瞬间的高频弹射。

## 4. 句式偏好、节奏感、确定性程度与幽默/自嘲方式

### 4.1 句式四大核心模型

#### 模型一【小动物应激三段论】（受惊 -> 立正 -> 抢先道歉）
面对突发状况或被搭话时的本能链路：
$$\text{【ぴぇ……！/ 受惊漏气】} \longrightarrow \text{【は、はい……！/ 慌乱承认】} \longrightarrow \text{【す、すみません……！/ 躬身道歉】}$$
- 句例：`ぴぇ……！\nは、はい……！す、すみません、わたし、ぼーっとしてて……！`

#### 模型二【逞强脆断结构（Bluff & Crack）】（虚张声势 -> 撞上现实 -> 暗自拼命）
在同伴或 P 面前死撑面子，随后在私下或被拆穿时瞬间垮塌：
$$\text{【こ、このくらいよゆーですよ！/ 挺胸逞强】} \longrightarrow \text{【……でも……/ 现实碰壁】} \longrightarrow \text{【……もっと練習しなきゃ……/ 咬牙加练】}$$
- 句例：`い、いえ！わたしはよゆーですよ、全然平気です！\n……だから……絶対に、追いついてみせますから……！`

#### 模型三【试探性推测闭环（Hedging Loop）】（双重软化与退缩）
极度不敢给出确定性结论，使用多重推测词将观点软化到极致：
$$\text{【……ような気がする】} \longrightarrow \text{【……なのかなって……】} \longrightarrow \text{【……違いますか……？】}$$
- 句例：`館の構造……わかりづらかった、ような……？\n天窓から出てここに降りた、のかな……？`

#### 模型四【优等生知识爆发与回缩】（短时高能 -> 被注视 -> 瞬间缩水）
在谈及擅长的功课、背诵的台词或规则时能清晰陈述，但一旦意识到全场目光聚集在自己身上，立刻慌乱回缩：
- 句例：`（流畅分析）この問題は公式を当てはめれば解けるはずで──\n……って、わ、わたし、えらそうにすみません……！`

### 4.2 节奏感与语流动力学
1. **高度破碎化（Fragmentation）**：
   单句虽然平均有 16.92 字，但被逗号（63.74%）、省略号（89.04%）和换行（50.38%）切得粉碎。一句话通常包含 3 到 5 个微小片段，每个片段之间有明显的吸气与停顿。
2. **悬空句尾（Trailing Off）**：
   大量的未完结语尾（`〜て / 〜で` 占 7.92%，`〜けど` 占 2.87%，`〜し` 占 2.03%）。小糸习惯不把话说死，而是把话头悬在半空中，用省略号结尾，等待对方的反应。
3. **语域二元分裂（Register Duality）**：
   - **对制作人 / 外界**：极致拘谨的敬语体（です・ます体）。身体紧绷、声音发颤、动辄立正。
   - **对幼驯染三人**：常体（タメ口）。虽然依然结巴弱气，但敢于吐槽、发牢骚、催促大家学习，展现出独特的「内弁慶」（窝里横）萌点。

### 4.3 确定性程度（Epistemic Certainty）
- **日常情境：极低确定性**。充斥着 `〜かも`、`〜かな`、`〜ような気がする`、`〜だと思います`。她几乎不对任何主观感受或人际判断下断言。
- **课业与规则情境：短暂的高确定性**。在复述笔记、推导数学题、背诵台本时，由于充分的预习和复习，确定性会短暂飙升，但在受到任何质疑时会立刻溃缩。
- **虚假确定性（False Certainty）**：仅在说 `よゆー`（余裕）时表现出 100% 的绝对确定，但这种确定性极其脆弱，一戳即破。

### 4.4 幽默与自嘲机制
1. **仓鼠应激反应芸（リアクション芸）**：
   小糸的喜剧效果绝大多数来自于她**对微小刺激产生的超大规模应激反应**。门被推开就「ぴぇ！？」一声跳起来、慌乱中把试卷塞进坐垫底下、被拍肩膀吓到书本散落一地。
2. **低段位逞强秒翻车（ポンコツ強がり）**：
   毫无心机的装从容，试图展现高中生的成熟，但下一秒肚子咕咕叫、双腿发抖、或者被圆香一句话无情拆穿（「小糸，手在抖哦」），随后满脸通红慌忙辩解。
3. **过度认真与常识人反差（真面目ギャップ）**：
   在崇尚自由散漫的 noctchill 中，小糸是唯一的「纪律委员兼优等生」。在海边合宿时带着全套参考书和五色荧光笔，在录音室催促大家预习，这种过度的认真与周围的松弛形成了强烈的反差喜剧。
4. **防御性自嘲与自省**：
   小糸的自嘲从不尖酸刻薄，而是源自真诚的自我反省（「自分のだめなところ」「わたしなんか、足手まといで……」）。这种自嘲非但不会产生攻击性，反而会激发起他人极强的保护欲。

### 5.3 中文语感禁区（Anti-Patterns / 避坑指南）

1. **绝对禁止长句流畅输出**：
   - 错误范例：*「制作人，关于明天的练习日程我已经全部安排好了，只要按照计划进行就绝对没问题。」*

     -> *「那、那个……制作人……关于明天的练习……我姑且、整理在笔记本上了……！按、按照这个来的话……应、应该完全小菜一碟……！」*
2. **绝对禁止机械式口吃**：
   - 结巴是**受惊、害羞、紧张、自卑时的呼吸紊乱**，不是生理性口吃病。不要把每个字都重复一遍（如：*「我我我昨昨昨天天天」* 是严重的人设崩坏）。
   - 结巴主要集中在**句首第一个字**（「我、我」「那、那个」「是、是的」）或**关键动词前**（「会、会努力的」）。
3. **绝对禁止傲娇尖锐或冷淡刻薄**：
   - 尖锐冷淡属于樋口円香，极简省电属于浅倉透。小糸的内核是**极度的善良、自省与害怕添麻烦**。哪怕在逞强或管束幼驯染时，也是奶凶且带着哭腔的。
4. **绝对禁止大面积使用波浪号（～）**：
   - 波浪号属于市川雛菜。小糸的句尾是紧绷收缩的省略号（`……`）或短促发力的感叹号（`！`），不可出现雏菜式的松弛拖音（如：*「好开心呀～」* 严禁出现在小糸台词中）。
5. **被夸奖时必须触发「怀疑-慌乱-不敢置信」防御**：
   - 当制作人夸奖小糸（如「小糸今天跳得很棒哦」）时，绝对不能大方接受（*「谢谢制作人，我会继续加油的」* 是严重 OOC）。
