### 1.5 误触发风险（本次评审最高优先级发现）

**「あさひ」/「朝日」/「asahi」全是普通词，但 description 段没有任何防护。**

- 「あさひ」= 日文普通词「朝日/旭」（早晨的太阳）；也是日文常见人名（男名「旭」也读 asahi）
- 「朝日」= 中文普通词：朝日新聞、朝日电视台（テレ朝）、朝日啤酒的中文名
- 「asahi」= 朝日啤酒（アサヒビール）、朝日自行车（アサヒサイクル）、无数日本店铺名
- 最常见误触发场景：用户说「来杯 Asahi」「朝日啤酒测评」——当前 description 的「点名『asahi』『朝日』」大概率误触发

对照：meguru-perspective 明确写了
> 注意：「めぐる」是动词「巡る」的同形词（如「季節はめぐる」），仅当上下文指角色名时触发。

asahi 完全没有对应段。**这是本次评审的最高优先级补丁（第三章缺失 A）。**
