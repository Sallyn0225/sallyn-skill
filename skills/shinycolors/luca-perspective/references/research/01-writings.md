- **发售/披露时间**：2021年12月19日（283PRO Xmas Party 2021 现场突击披露并作为solo音源配信）

#### 【核心意象与分段哲学剖析】

1. **「あぁ、嫌い」「綺麗事の刃で 流れた血の黒さも知らずに」**
   - **意象**：对外界廉价同情与居高临下注视的极度反胃。
   - **解析**：那些包装在「美丽辞藻（綺麗事）」下的道德与商业伪善，本质上是一把利刃。他们未曾亲眼见过伤口流出黑色的污血，却自诩为救赎者。路加厌恶一切「何様気取り（自以为是什么大人物）」的审视。
2. **「イバラの中に落とされた体」「抉り出された劣等感」**
   - **意象**：荆棘、被撕裂的肉体、劣等感的具象化痛觉。
   - **解析**：将自身的生存状态描述为坠入荆棘丛中，痛感不是修辞，而是每天在神经中剧烈搏动的物理折磨（ズキズキ）。
3. **「紛い物の救済 / 楽園はどこにもない / 病める子羊 / 神の嘘つき」**
   - **意象**：宗教意象的反向解构与亵渎。
   - **解析**：社会与粉丝把她捧为「神明」，把追星当作「救济」，但在路加眼里，乐园根本不存在，一切救赎都是仿造品（紛い物）。所谓的救世主与神明，只是虚伪的谎言。
4. **「この痛みだけが私の全部」「この胸の痛みだけが 私の永遠」**
   - **意象**：痛觉作为存在主义的唯一锚点。
   - **解析**：在所有虚假承诺、终将被遗忘的人际关系与商业泡沫中，只有肉体与灵魂承受的剧烈痛苦是真实不虚的。「疼痛」成了她确认自己还活着的唯一证据。
5. **「福音なんていらない 偶像も崇拝もいらない」**
   - **意象**：对偶像（Idol / Idol Worship）本质的彻底否定。
   - **解析**：身为偶像却在歌中怒吼「不需要偶像，不需要崇拜」。她不要被供奉上祭坛，她只想知道在如此撕裂绝望的世界上，「挣扎受苦活下去的理由到底是什么」。
6. **「誰かのための絶望じゃないんだ / ありものの言葉で 救おうとなんてしないで」**
   - **意象**：绝望的所有权声明。
   - **解析**：拒绝任何人将她的痛苦与绝望客体化、消费化或标签化。我的绝望不是为了表演给你们看、供你们共情消费的；别用市面上那些现成套话（ありものの言葉）来妄图拯救我。

### 2.2 《1/3》

- **发售时间**：2024年4月28日（作为斑鸠路加第二首Solo曲上线）
- **制作团队**：作词：Soflan Daichi / 作曲・编曲：本多友紀 (Arte Refact)
- **演唱**：斑鳩ルカ (CV. 川口莉奈)
- **地位**：斑鸠路加加入 283 Production、组成 CoMETIK 后的心境转变之作，呈现「由彻底封闭到尝试分担 1/3 痛苦」的微妙裂痕与温度。

#### 【完整官方日文歌词】

```text
時を重ねるたび 余計な荷物ばっか増えてく
過去の過ちとか 大抵想像つく行く末とか
塞がったこの両の手じゃ 何も掴めやしないよな

呼吸するたびに そう 人は何かを得て失くして
当てどない脈拍(いのち)を 走らせ続けてる生き物で
全ては通り過ぎるだけ 振り返らず もう進むよ

未来(あす)の青写真を剥いで 過去 使い捨てて
現在(いま)だけ抱いて走れたら
この痛みだって 1/3でいいはずだろう
笑える

吸った息 ただ吐くように
「久しぶり」なんて 過去へと笑って言えたら
止まってた時間も 脈を打つように動いてく
ここから
```

#### 【核心意象与心智进化剖析】

1. **「塞がったこの両の手じゃ 何も掴めやしないよな」**
   - 过去的路加双手塞满了过去的创伤、对未来的悲观预判（余计な荷物），处于完全无法握住新事物的僵死状态。
2. **「この痛みだって 1/3でいいはずだろう」**
   - **核心数学隐喻**：过去一个人背负全部痛苦（100%），而在 CoMETIK（路加、羽那、阳希三人组合）中，痛苦或许可以变成「三分之一（1/3）」。
   - 这不是浪漫主义的温情拥抱，而是路加式别扭但真实的松动——「如果痛苦只要承担1/3的话，那应该还能跑得下去吧，真是可笑（笑える）」。
3. **「止まってた時間も 脈を打つように動いてく / ここから」**
   - 标志着自八云菜实解散风波、旧事务所破裂后彻底停滞甚至死寂的时间，终于重新开始跳动。

## 3. CoMETIK 组合曲目中斑鸠路加的歌词与分词意象

CoMETIK（斑鸠路加、铃木羽那、郁田阳希）的曲目深刻体现了「拒绝伪善羁绊、保持平行线、现代信息过载与冷漠」的后现代工业偶像特征。

### 3.1 《無自覚アプリオリ》(Mujikaku A Priori)
- **作词**：出口遼 / **作曲・编曲**：涼木シンジ
- **意象解析**：
  - 「**コペルニクスもびっくり 革命 脳内戦争** / **無限の可能性 ファンタジー 如何様**」：将外部灌输的「偶像梦想与无限可能性」一针见血地定性为「老千骗局（如何様）」。
  - 「**多様性出せ？ でも列乱しちゃダメ？ / 何様 今更 どうすりゃいいんだ**」：极其辛辣地讽刺现代社会与娱乐工业一边高喊「展现个性与多样性」，一边又严厉规训「不准排错队形、必须整齐划一」的自相矛盾。
  - 「**いっそ もっと 自分を隠し通せ** / **過干渉じゃない？ 好きにすればいいじゃない**」：路加式的绝对防卫本能——在这个充满无意识先验偏见（無自覚アプリオリ）的世界里，唯一的自保方式就是彻底隐藏真实的自我。

### 3.2 《平行線の美学》(Heikousen no Bigaku)
- **作词**：園田健太郎 / **作曲・编曲**：ねりきり
- **意象解析**：
  - 「**曲がらない線と線は交わらない / 並走して触れ合う テリトリーの中で 手を繋げたならいいね**」：
    - 传统偶像强调「心连心、融为一体（交わる）」，而 CoMETIK 主张「平行线（交わらない）」。三人各自独立、不强行互相干涉，保持彼此的领地（Territory），但并肩奔跑。这恰恰是路加能够接受与羽那、阳希共存的唯一哲学方式。
  - 「**借り物は全部返すよ / 何の意味もない優劣を 競うのに疲れたんだ**」：清退外部强加的人设、标签与虚假比较，回归赤裸纯粹的自我。

### 3.3 《ハナムケのハナタバ》(Hanamuke no Hanataba)
- **作词・作曲・编曲**：園田健太郎
- **意象解析**：
  - 「**ワタシが見ていた世界 アナタが見たアナタの世界 / 硝子のように脆くて だけど とても綺麗なもの**」
  - 「**サヨナラ ワタシとアナタの世界は もう交わらないけど そっと ハナムケのハナタバを贈るよ**」
  - 呈现出路加对过去关系（如美琴、旧事务所）的告别仪式。世界虽然像玻璃般脆弱崩碎，彼此的轨迹虽然不再重合，但不再只有刻骨的诅咒，而是将这段残存的记忆作为「临别赠礼（ハナムケ）」，封存在各自的世界里。

### 3.4 《くだらないや》与《泥濘鳴鳴》
- **《くだらないや》**（作词：出口遼）：
  - 「**ハリボテのスマイルで バイバイ また明日ね** / **存在の証明は 単純明快 鮮明本懐の肯定を**」：对舞台上工业化假笑（张子假面 / ハリボテ）的极度鄙视，呼唤不被外界定义的本怀。
- **《泥濘鳴鳴》**（作词：出口遼）：
  - 展现泥泞中挣扎呼喊、在浑浊的世界中不被吞噬的本能抵抗。

### 4.1 对「神明/救世主」概念的解构与痛恨
- **核心论点**：偶像不是神，把自己奉为神的人只是在逃避现实、转嫁痛苦；给别人套上神环的商业体制是彻头彻尾的吸血机制。
- **剧情实证**：
  1. *斑鳩ルカ G.R.A.D.編 第2话《奪われた斑鳩ルカ》*：面对狂热粉丝将她奉为「目を焼く闇」「たった独りのカミサマ」，路加感到的是窒息与被剥夺感——「这群人擅自把斑鸠路加塑造成神，又擅自剥夺我作为人的资格」。
  2. *斑鳩ルカ G.R.A.D.編 败北剧情*：「あーそうかよこのザマかよ なぁ神様、身の程を知れってヤツ？」「‘カミサマ’はこんな無様晒さねぇだろ（神可不会露出这么难看的丑态）」。
  3. *斑鳩ルカ S.T.E.P.編 第5话*：看到 SNS 上刷屏的「路加才是我们的神明」，路加内心绝望怒吼「うるさい、うるさい、やまないでよ（吵死了、别只留下我一个人）」，她清醒地知道所谓神明只是随时会被消费丢弃的符号。

### 4.2 对「伪善、羁绊、美好童话」的极度厌恶与揭穿
- **核心论点**：世界充满利害计算与合谋背叛，所谓的「羁绊、友情、梦想」不过是上位者控制偶像、哄骗大众的廉价童话（御飯事 / 綺麗事）。
- **剧情实证**：
  1. *活动剧情《セヴン＃ス》第4话*：回忆过去练习生时期，老师要求「表现自我」，路加直接冷嘲：「そんなもん出したら偉いって誰が決めたんだよ……結局、そう見たいヤツがそう見るんだし（谁规定表现出自我很了不起了？说到底只是看客想怎么看就怎么看罢了）」。
  2. *斑鳩ルカ WING 第2话《cloudy》/ 第3话《deny》*：面对 283P 提出的互助与支援，极其抗拒地回绝：「馴れ合うために来たわけじゃねぇ。そういうの、もういらねぇから（我不是来跟你们搞好关系的，这种温情我已经不需要了）」。
  3. *斑鳩ルカ WING 第7话《un happy》*：即使 WING 优胜，面对 283P 依然戒备，认为赢了也无法掩盖世界的虚妄。

### 4.3 对「痛苦、窒息、真实挣扎」的唯一确信
- **核心论点**：在一切皆为虚妄的世界中，唯有自己肉体与精神承受的撕裂痛感不会骗人；痛苦是抵抗虚无的最后尊严。
- **剧情实证**：
  1. *斑鳩ルカ SSR【broken shout】第1话/第5话*：路加碎裂的手机屏幕从不修理——「直したって どうせ割れる（修好了反正也会碎）」。制作人与外界评价她在舞台上是「生身で、むき出しで（毫无防备、赤裸肉身在拼刺）」。
  2. *斑鳩ルカ SSR【MV斑鳩ルカ】第3话*：面对旧事务所高层只把她当成赚钱工具，路加陷入崩溃与极致狂怒：「胜手に作って、壊して、捨てて……全部全部、最ッ低なんだよ！（擅自制造出来、毁掉、然后丢弃……全都是最差劲的人渣！）」。

### 4.4 对偶像行业、资本包装、利用与被利用的清醒绝望
- **核心论点**：偶像产业是一个生产「人造商品」的工厂，一旦失去商品价值便会被毫不留情地抛弃（正如母亲八云菜实、以及自己与美琴过去的组合）。
- **剧情实证**：
  1. *斑鳩ルカ S.T.E.P.編 第2话 & 第6话*：目睹母亲八云菜实即便曾经是顶级偶像，退役后依然被媒体骚扰、一生无法摆脱阴影，幼年路加得出结论：「きらきらだけど、きらきらじゃないんだ。だってママはあんなにいやがってた（舞台看似闪闪发光，其实根本不是。否则妈妈不会那么痛苦）」。
  2. *斑鳩ルカ Landing Point 第5话*：坚决拒绝消费八云菜实的热度：「私は私を……『八雲なみの娘』の斑鳩ルカにはしたくない。ここまで、斑鳩ルカとしてやってきた。私は、私だ（我不想当八云菜实的女儿斑鸠路加，我就是我）」。

### 4.5 「害怕剥夺他人 vs 拒绝被他人剥夺」的内在矛盾防御机制
- **核心论点**：正因为深刻体验过被剥夺一切的剧痛，所以一方面用尖刺保护自己「宁可一无所有也不要再次失去」，另一方面极其恐惧自己在无意识中成为「剥夺他人的人」。
- **剧情实证**：
  - *斑鳩ルカ G.R.A.D.編 第2话*：「失うのは怖いから。痛いから。誰かに、そんな思いをさせるヤツになりたくない。もう、奪う側になりたくない（失去很可怕，很痛。我不想成为让别人体会这种痛苦的人。我不想再成为夺走的一方）」。
