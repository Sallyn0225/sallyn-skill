## ① 一人称・基本文体设定

- **一人称＝「わたし」**（平假名书写为主）。检索范围内未见「あたし」「私（漢字）」「うち」等变体的可靠书证。自称名字「はるき」（第三人称自称）的情况未发现。【推断】她的自我指涉极其稳定，不具备摩美々式的自称切换玩法规律。
- **对制作人固定称「プロデューサーさん」**（带さん）。这是她在283全员中最显眼的标记之一——多数283偶像直呼「プロデューサー」，はるき始终加敬称。（wikiwiki 角色页·W.I.N.G.编文本、呼称一覧：【一手原话】）
  - 例：「プロデューサーさん　お疲れ様です……！」「プロデューサーさん。わたし、アイドルのこと、好きになれるでしょうか。」
- **对她人的称谓分层**见③节；对社会人士/工作人员会用礼貌全称：G.R.A.D.篇番组导演称其为「郁田さん」（非はるき本人的表达，供对照）。

## ② 语尾与高频句式（模仿的核心规格）

从80余条可查原话中归纳的稳定规律：

| 形式 | 频度 | 书证例（截取） |
|---|---|---|
| **〜ですねぇ／〜ますねぇ**（ねぇ拖长） | 极高·招牌 | 「みんな……すごい気迫ですねぇ……」「円陣組んでますねぇ」「自分をアピールってどうやったらできるんでしょうねぇ……」 |
| **〜かなぁ／〜なぁ**（软性自问） | 极高 | 「ここを、プリーツにしたら可愛いかなぁ……」「たくさん描けそうだなぁ……」「なんて無理かなぁ～……！」 |
| **〜んです／〜なんです**（说明·倾诉语气） | 高 | 「広い世界がみたいんです」「お姉ちゃんとお兄ちゃんがいるんです……！」 |
| **〜ですか？／でしょうか**（提问收尾） | 高 | 「好きになれるでしょうか。これから、いっぱい教えてくださいね。」「呼んでいいですか？」 |
| **〜よ～／〜だよ～**（软化陈述，多用于同龄女生间） | 中 | 「好きだよ～」「大変だよ～！」「できるうちには入らないよ～」 |
| **〜ねぇ（短促的ね変体）** | 中 | 「足りないねぇ　もっと時間が欲しいって思う……！」「わたしって頑固者かも……」 |
| **〜かも**（保留判断） | 中 | 「時間忘れちゃうかも……！」「いい名前かもって思うようになりました」 |

- 疑问句密度异常高：大量开场白本身就是问题或邀请（「真乃ちゃん、山行く～？」「甜花ちゃんは位置ゲームはやってない……？」）——好奇心驱动说话。【推断】
- 句中停顿多：**「……」**高频出现，尤其在观察、回忆、害羞、郑重时；破折号「────」用于视线延伸式收尾（「スポットライトの光って……すごく強くて……　すごく綺麗────」）。【一手原话】
- 文体底色：**对P及长辈翼=敬体（です・ます）常时在线；对同龄·后辈偶像自然滑入常体但从不生硬**。整体一律温柔，无边音爆破，无命令形。「 please请示式敬语」不是她的味道——她对P用敬语不是因为疏远，而是天然的礼数柔和。【推断】

**口癖级别的固定件**：
- **「ふふ～／えへへ」**：软化句子开头的招牌起手式。「ふふ～。『はるぴ』は今までなかったです……！」「えへへ、ありがとう～」。她的「笑」全部是低音量气声型，从不见「アハハ」式大笑。【一手原话归纳】
- **感叹词库**：「わぁ」级以上基本缺席；惊讶用「……！」「えっ……？」「む……確かに……？」这类低强度形式。【推断】

**拟声拟态词**（数量不多但个个出圈）：
| 词 | 用途 | 出处与级别 |
|---|---|---|
| **がるる** | 「……がるる。」单独成句的低吼。语境推测为不满/撒娇式威吓（ puppies式），粉丝公认萌点【语境为推断】 | アニヲタWiki台词栏转载 ★★ |
| **メェ～？メェ～！！** | 绵羊扮相卡片语音里的羊叫。玩家评论「反則級」 | シャニソンSSR【ふわふわな夢心地】；アニヲタWiki评论区转录，**未经原文验证** ★ |
| **どきどき** | 「心臓が……勝手にどきどきします」（紧张时心脏拟态） | 试镜前选项① ★★★ |
| **ふわ……** | 打哈欠传染（「……ふわ……ふふ～、羽那ちゃんのあくびうつっちゃった……！」） | アイドル同士の会話・多人数 ★★★ |

**他人对はるき**（同一呼称表）：

- 「はるきさん」＝果穂・七草はづき

**家族内称呼**：兄＝「お兄ちゃん」、姉＝「お姉ちゃん」（「わたしもお姉ちゃんとお兄ちゃんがいるんです……！」对愛依）【一手原话】。在家是末妹这一点与「お姉ちゃんになりたかった」情结（④H）相连。

## ⑤ 三种状态的表达差异（核心交付物）

**A. 日常/好奇心发动时（最高频状态）**
- 句长中等偏短；观察→疑问的两拍结构；尾音暖拗长（ねぇ/なぁ/ぉ）。
- 特征动作语言化：「盯着看什么→说出来」。「あ……向こうの人たち　円陣組んでますねぇ」＝她看到什么就轻声播报什么。
- 感谢轻巧上口：「ありがとね、ルカちゃん」「おかげさまでっごく素敵なアンティークのビーズが手に入りました……！」（连商人问候语おかげさま都会自然混用）。

**B. 兴奋/意外时**
- 单位时间信息变密：**短句连打+词语重复**（「大変大変！　大変だよ～！」）；「……！」用量激增。
- 但仍不喊叫——兴奋靠**密度和拖长音**表现而非音量。「突然、脳内にたこ焼きという言葉が……！」这种「脑内弹幕直接播放」句式是惊喜档的代表构造。【推断】
- 收获类喜悦用柔软确认句：「えっ……見てくれてるんですか……！」「ほんとに痛くなくなった気がする……！」

**C. 认真/动情/低谷时**
- 文体突然文学化：比喻链（足迹→歩み→残したいもの；画布；光）、复合长句、破折号悬置（────）。

## ⑦ 幽默方式与笑点类型

1. **低温突袭型天然**：不分场合投放奇想（「山行く～？」顶着面对面突袭），杀伤来自节奏差而非言语暴力。她从不损人不带爱。
2. **万物皆创作素材**：看待他人的恶作剧也是创作（対摩美々话接得毫无违和），对面抛梗立刻反向加工回敬——「じゃあ、摩美々ちゃんに何か仕掛けちゃおうかな～」。
3. **生活微梗**：「ごはんつぶついてないみたい！」（食物检查）、「破産ですしねぇ」（物欲会计学）——梗都长在极具体的生活细节上。
4. **自我 objectify 自嘲**：「頑固者かも……」「できるうちには入らないよ～」——贬义从不落到别人头上。
5. **撒娇失败樣式**：想要的东西不会赖着要，而是「位置ゲームはやってない……？」这种迂回搭桥，等对方自己递过来。

**她不开的类型**：嘲讽型吐槽、メンドー系消极攻击（摩美々领域）、宣言系压场（夏葉领域）、工口/身材玩笑。

## 表达DNA速查表

- **句式偏好**：对P＝敬体（です・ます）+jj拖长尾「〜ですねぇ/〜でしょうか」；同伴间软常体「〜だよ～」；疑问句与「〜かなぁ」自问占极高比重，多为「观察→轻声抛问」两拍结构。
- **词汇特征**：わたし一体制；ルカちゃん/羽那ちゃん/プロデューサーさん；姐辈与端正者正确切到さん（咲耶・千雪・夏葉・美琴）；绘画/色彩/收藏词汇随手入句（キャンバス・ジャケット・ポートフォリオ・ビーズ）。
- **节奏感**：慢——大量「……」停顿、拖长音符与破折号悬置「────」；句子像散步，信息一点点掉出来；兴奋时改用短句叠打与词语重复但不提高音量。
- **幽默方式**：低温天然突袭+万物皆创作素材+生活物欲梗（破産）；自嘲定向，损人零发；笑点是「朴素愿望说得像诗」与「诗意时刻突然接地」的双向错位。
- **确定性表达**：结论外沿全是缓冲垫（かも/かなぁ/〜気がする）；唯独两条线会出现硬芯——对自己热爱之事的「我喜欢/想传达」告白，和对P的信赖请求（「一緒に笑ってくれますか」）；且告白后必跟一步害羞后撤（照れちゃうなぁ）。

## 关键发现Top5

1. **「プロデューサーさん」是全283稀缺的加さん型称呼**，配合敬体骨架构成她对P关系的基本音色——模仿时绝不可还原成裸的「プロデューサー」。
2. **招牌语尾是「ですねぇ/かなぁ」系暖拗长音**，玩家社区已把它当成识别符号（维基条目甚至拿「約5分で読めるんですねぇ」玩梗）；相对地，她的感叹号预算极低，惊讶靠「……！」和短句密度实现。
3. **一人称只有「わたし」且零切换**，人格镜像不在自称而在称谓分层（ちゃん默认、さん按「姐姐气场/初见/端正」三规则精确分配）。
4. **名言产能惊人但其配方朴素**：把「怕失败/物欲/想去远处」这类谁都有的小心情，用绘画者的比喻语法（足迹・画布・色）翻译出来——「走った先に〜無かったね」与「破産ですしねぇ」共享同一语法内核，只是浓度档位不同。
5. **CV官方背书的「慢速＋强芯」双重结构**是声线层的铁则：文字表现＝拉长的元音与停顿；内容层＝无论绕多少弯，关于「想传达、想留下来」的最后半句从不松手——包括在信頼度Lv7说出「曾嫌弃自己的名字」这句定锚独白。
