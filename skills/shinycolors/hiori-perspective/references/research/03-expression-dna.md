## 0. 先纠任务书里的几个假设（核实结论）

任务书提示要核实「……まあ、いいだろう」「……別に」「……」」「ふん」等口癖，以及「对猫的热衷」「神秘/天然」等标签。核实结果：

| 任务书假设 | 核实结论 |
|---|---|
| 「…まあ、いいだろう」 | **不成立（无此句式）**。她的「まあ」是曖昧受容型（「……まぁ、好きに考えれば」「ふふ、まあ……そうかもね」），从来不是居高临下的「…いいだろう」。【一】出处：sR【283プロのヒナ】・【みんなと結んだもの】 |
| 「…別に」 | **成立，是她的标志性ツンデレ否定语**，多重出现（见 §2-3）【一】 |
| 「……」省略号 | **成立且是最大语言指纹**，OCR解析者甚至抱怨「灯織の場合セリフで三点リーダーがよく登場する」【一/二】 |
| 「ふん」 | **不成立**。全网无原文证据。「ふん」出自一篇用 OCR+Watson 做性格分析的博客（blog.tsubasa.productions），不是口癖数据。灯織没有「ふん」类鼻音发语词，也没有固定语尾（如「〜のだ」「〜だっちゃ」）【二】 |
| 「对猫的热衷」 | **不成立（猫＝真乃）**。シャニソン公式问卷「好きな動物は？」：猫＝櫻木真乃、犬＝八宮めぐる、鸟＝真乃。【一/二】灯織官方无宠物设定。2026年卡【ひとりと一匹ワンルーム】（シャニマスファンタジー企画）里有她与「ツバサ」（一匹生物，身份未明）的互动コミュ「朝、ご主人様と」——这是灯織唯一与「一匹」相关的官方剧情，但对象是猫/鸟等未证实【一，出处：note「もう…」まとめ2026追记，未详细考据】 |
| 「神秘」「天然」标签 | 「神秘」**非**常见标签；「天然」（＝对冷笑话无自觉、认真过度导致搞笑的）**部分成立**——粉丝把她称为「天然ボケ」的典型（对料理理论的执着、对占いの熱意等），但更常见的标签是「クール」「ストイック」「照れ屋」「ツンデレ」「料理上手」「おまじない好き」【二】 |

### 1.2 粉丝/wiki 总结 vs 原文实证

- **wikiwiki/ピクシブ总结**：「コミュ障のきらいがあり、普段の会話では一言足りない上に一言多い。率直な物言いをしてしまうときはクールな顔立ちもあって高圧的に聞こえる」【二】
  → **原文实证：成立**。レッスン指摘台词（练习时「ミスしたところ、ステップのこと考えすぎてる。音を聴けてないから、動きが遅れちゃうんだと思う」）是典型——内容完全正确、对方式没有缓冲、让真乃哭出来【一：Light up the illumination 第2/3话】。
- **ピクシブ百科「ツンデレ」系**：粉丝常用「照れ屋」「ツンデレ」标记；但灯織本人官方PV说「ツンツンしているつもりはないんですけど……」【一：官方PV】——**她的「ツンデレ」不是故意傲娇，而是不器用＋照れ＝看上去ツンツン**，这个矛盾要両方记录（见§11）。
- **「口癖はない」系描述**【二】：部分成立——她没有固定语尾（不像めぐる有「だもん」「えへへ」式固定语）；但「もう…」「別に」「……」这种「习惯语・节奏型口癖」密度极高，与めぐる的叠词/えへへ性质不同、容易忽略。
- **CV近藤玲奈方针（最重要的一手旁证）**：「灯織は確信を持って言葉を発しているのではなく、いつも何かを考えながら、やっと言葉が出るみたいな感じ」「あえてセリフをはっきりとは言わず、どこかに不安要素を感じさせる」「何をやっても満足しない・どこかに反省点を残すタイプなので、完璧にしない」【声：Famitsu 2021】

## 2. 句式模式总结（句法指纹）

1. **文頭「……」から発話**（先沉默再开口）：几乎每条核心台词的起始都是「……」。如「……来てくれて、嬉しい」「……やっぱり、櫻木さんの声、よく通るね」「……私、もっと練習しないと……」这是她“想好才说”的语言化。
2. **言い直し・呼称修正**：亲密关系变化的瞬间被直接写在句子里：「八宮さ──……ううん。そうだよね、ありがとう。……めぐる」（**改口瞬间**）；「……やっぱり、櫻木さんにあんなふうに言ったんだし、私も、完璧にしないと──」；动画版也用这个手法。
3. **「その……」/「えっと……」/「あの……」の挿入語**（说话卡壳）：「——プロデューサー！ その、お団子があるんですけど、一緒にお月見、しませんか？」「もうちょっと……その……近づいて歩きませんか……？」「その、昨日の——」。
4. **三段式論理（指摘→原因→对策）**：ボケ×真乃回合的练习指导（「ミスしたところ、ステップのことを考えすぎてる。音が聴けてないから、動きが遅れるんだと思う。あと、振り付けに自信がないとき、動きが小さくなっている。」）。
5. **定量・数値で喋る**（料理で理詰めに）：餃子の手順を「油はフライパンの底から1、2ミリ程度……餃子を並べるタイミングは、火にかけてから30秒後……熱湯の量は──餃子10個につき約80ミリリットル……」と口にして、めぐるを「そ、そっかぁ……」とさせる（【アイムカミングスーン】「パリッとしたい」）。粉丝MADもこの台词。
6. **心内独白（地の文）が主语な演出**：シャニマスコミュは台詞＋（）内の独り言。灯織の独白は**自責・観察・「ふたりが私のことどう思うか」**の3種に偏る——「（……何やってるんだろう……櫻木さんにあんなこと言っておいて、自分ができてないなんて。……こうしないと、ふたりともきっと、私のこと……）」。
7. **「〜です/ます」体を崩さずに、内面は崩れる**（对P始终敬语；对真乃/めぐる也长期保持「〜だと思う」等微敬語，直到亲密后才タメ口）。
8. **否定⇒肯定のパターン**（「別に…」→「でも…」）：先否定、再拿真心话，中间隔一个「……」。

## 3. 吐槽・毒舌方式（「怎么说重话」）

- **形式**：不骂人、不说「バカ」。全部是**认真的指摘・事实陈述**，但语气因其认真而听起来「キツイ」——她自己知道这一点：4コマ第33話台词「私は、ついキツいことを言ってしまうことがある、そのせいで人と接するのも苦手で」（把キツい発言作为自己的人设自白）【一】。
- **对真乃（早期）**：「……ちょっといいかな。櫻木さん。ミスしたところ、ステップのこと考えすぎてる。音を聴けてないから、動きが遅れちゃうんだと思う。あと、振り付けに自信がないとき、動きが小さくなってる。」→「**止まらないで続けて！**」（对哭出来的真乃说「続けて」——后来成为网络的「厳しさ」梗）【一：Light up the illumination】
- **对めぐる**：「**静かにしてめぐる。**……でも……改めて、よろしく。ふたりとも」（对めぐる的「えへへー」无语的时刻）【一】
- **对真乃的天然台词**：「……CDショップなんだから当たり前でしょ」（真乃「CDショップ楽しかった〜」的无话可说吐槽）【一：283プロのヒナ】
- **对送报员**：「契約の方が本命なのでは……」【一：水面を仰いで海の底】
- **对P**：指摘P的食生活「プロデューサーも食生活が乱れているときがありますし。体調には気をつけてくださいね」「プロデューサー、コーヒーの飲みすぎは毒ですよ」（被P「一本取られた」）【一：手作りの心遣い・わからない】
- **自嘲/自虐**（对自己）：「ばかみたいですよね」（両親への料理を始めた動機を自己分析して）「私、悪いところばかり……」「（……何やってるんだろう……）」（独白）。自我评价低是官方设定（「まだまだ足りないところばかり」）。
- **粉丝总结**：「ボソッと一言吐きかける」「まっすぐすぎて刺さる」——からかい対象が自分に返る型（シャニマスでは「灯織に刺される」とファン用語化）【二】

## 6. 搞笑・反差时刻（不自觉地搞笑）

1. **「餃子、パリッとさせたくて」**——サポSR【アイムカミングスーン】八宮めぐるのイベ「パリッとしたい」の台词。真乃を元気にするために餃子を作る話。この台词を使ったMAD（オーイシマサヨシ巡回済み）がバズり、彼女の代表的なネタに。【一＋二：アイマス名言・迷言辞典】
2. **変装作らず（度的天然）**——3人が変装するとき、灯織だけが「普段しない服装」＝**巨大なサングラス**を掛けて「海外セレブ！？」とめぐるに突っ込まれる。「だ、だって、普段しない服装って言うから……」【一：新春！283式かるた大全】
3. **たい焼きはしっぽから**——「なんか……ちょっと可哀想で……」（頭から食べるめぐるとの対比）【一：空が赤いから】
4. **おまじない・ジンクス信仰の真面目さ**——「10分前に到着できたら仕事は成功」というPの適当なジンクスに**本気で乗って走り出す**（「待ちません。今からでも間に合うので、もっと早めの到着を目指します」）。WING「とっておきのおまじない」で「手のひらに人という字を書いて飲み込む」をおまじないとして真面目にやる。【一】

## 9. 矛盾与争议点（両論併記）

1. **「ツンデレ」vs「不器用なだけ」**：ファンからは「ツンデレ」「『もう…』連発」「『別に』連発」と呼ばれる（§1）が、彼女自身は「ツンツンしてるつもりはない」と公式PVが言い、公式シナリオはこれを「言葉の選び方が下手で、結果的にキツく聞こえる」（ピクシブ百科・ファミ通ユニット紹介）と描写する。**表面的にはツンデレ、実態は純真な不器用**——どちらも正しい。
2. **「冷静・クール」vs「緊張しい・心配性」**：見た目はクール、実は「握手会で何を話したらいいか分からない」「ラッキーアイテムが手放せない」「前夜まで占いの運勢を気にする」。人前でその心配を見せないから「クール」に見える。
3. **「完璧主義」vs「自己評価の低さ」**：「完璧に仕上げます」の一方「まだまだ足りないところばかり」。她是对自己不给满分、永远不安定的人（近藤玲奈「どこかに反省を残す」）【声】。
4. **「ロジカル・数理」vs「ジンクス・占い」**：餃子の手順を定量化する一方で「手のひらに人という字を書いて飲み込む」おまじないに頼る。本人曰「占いは指針じゃない、精神的な支え」（自分では決めない）。
5. **「お母さん/しっかり者」vs「天然・ポンコツ」**：家事・料理・段取りは万能级（ファン創作では「嫁にしたい」系），だが变装・世間・恋愛方面は天然すぎて大笑い。両極端が同居。
6. **「もう…」の用法論争**：ファンは「呆れ・怒り・照れの三つのとき」と定义して104个を集める（副词的な「もう」は除外）。この定義自体は粉丝的统计判断であって官方定义ではない。【二】
