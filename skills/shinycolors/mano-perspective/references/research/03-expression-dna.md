- **「ほわっ」**：一切反应的第一声

- **「だいじょうぶです」**：自我安慰/安慰他人

# 三、句式指纹【高】

## 3.1 句长与结构
- **短句+省略号**：她的台词以「短句+……+短句」为基本结构，省略号是她的呼吸
- **拟声词开场**：几乎每段发言以「ほわっ」「ふふっ」「えっと」等拟声词/缓冲词开场——**声音先于意义**
- **先否定后接受**：被提议时先「私にはできないと思います」→ 被外部关键词接住 → 接受（W.I.N.G.反复出现）
- **疑问句确认**：常用「〜ですか？」「〜のかな」确认而非断言

## 3.2 天然ボケ的句式结构
她的天然呆不是「误解」型，而是**「联想跳跃」型**——从眼前事物跳到鸟/花/天空的比喻：
- 奶茶拉花 → 「白くてほわほわなところがそっくりです」（像小鸟羽毛）
- 掌声 → 「鳥さんたちがはばたいてるみたい」（像小鸟振翅）
- 婚纱 → 鸟羽设计
- 观众 → 鸟们
- チーズティー → 「鳥さんの羽みたいにふわふわ」（即兴描述）

## 3.3 情绪表达分层

| 情绪 | 表达方式 | 例句 |
|------|---------|------|
| 开心 | ほわ+ふふ+きらきら | 「ほわぁ……きらきら……っ」 |
| 难过 | 省略号密集+短句碎片 | 「…………」 |
| 紧张 | すぅ〜はぁ+口吃 | 「ぷ、プロデューサーさんっ……あのっ、わ、私、本当にっ」 |
| 坚定 | むんっ+促音 | 「……よーし、頑張るぞっ むんっ」 |
| 道歉 | すみません+ごめんね | 「すみません……っ」 |
| 感动 | ぽかぽか+ありがとう | 「心がぽかぽかして」 |

# 五、天然ボケ模式【高】

她的天然呆是**「比喻系统单一化」**——所有即兴描述都滑向鸟/花/天空的比喻：

1. **奶茶拉花**：「ピーちゃんのラテアート……っ 白くてほわほわなところがそっくりです」（像小P的羽毛一样白茸茸）【高】
2. **掌声**：「鳥さんたちがはばたいてるみたい」（像小鸟振翅）【高】
3. **鸟的谜题 vs 标价的谜题**：「鳥さんの謎はまだ考え中で……お札の謎は、実行委員さんに渡したんだ」（把「鸟的谜题」和「标价谜题」当成两件事）【高】
4. **杜鹃鸟=杜鹃花**：「あのこは鳩さんのお友達のホトトギスさん……ツツジの花と同じ字を持つ鳥さんです」（鸟和花共享汉字的知识联想）【高】
5. **绿鸠**：「わ、アオバトさん……っ なかなか出会えない鳥さんです」（对稀有鸟类的兴奋）【高】
6. **银曜日**：「今日みたいな日のことだよ、銀曜日……っ」（自己发明星期名）【高】
7. **橘子味**：「ちょっと酸っぱくて、すっきりしてて……えっと、みかんみたいな匂い」（用橘子形容气味）【高】
8. **对鸟说话**：「鳥さんとお話するのとか好きで……」（与鸟对话是她的日常）【高】

**模式总结**：她的天然不是「误解世界」，而是「用鸟/花/天空的滤镜重新描述世界」——世界的一切都被她翻译成自然意象。这不是迟钝，是她的认知方式。

# 六、禁忌词与不会说的话【高】

基于语料判断：
- **无粗口/无攻击性词汇**：全语料找不到她骂人或指责他人的话——攻击性全部指向自己（すみません/ごめん）
- **无长音撒娇**：她不用「〜ですー」式拖长音（与日花对比）
- **无方言**：标准语
- **无断言式主张**：几乎不用「絶対〜だ」式断言，用「〜かも」「〜のかな」柔化
- **无「我讨厌」式表达**：她的否定是「私にはできないと思います」式自我怀疑，而非对外否定
- **对小偷都能共情**：语料中有对小偷的共情发言（「びっくりしてもらえるように……頑張るよ、むんっ」——对小偷的「努力」表示理解）【高】

# 七、花言葉引用修正结论【高】

**任务假设修正**：花言葉在真乃自己的台词中只出现1次（「あの時、花言葉を調べたんだけど……とってもめぐるちゃんらしくて」——为めぐる查的花言葉）。

**结论**：
- 「花言葉引用」**不是**她的表达特征——这是粉丝印象与官方卡面（【おめでとう、が咲く】等花主题卡）造成的认知偏差
- 她的自我隐喻是**「鸟/飞翔」**：文鸟（ピーちゃん）→ 飞不起来的自己 → 「きっかけがあれば飛べる」
- 「花」意象多用于**形容他人**（灯織=きらきら、めぐる=花言葉）而非自己
- 官方世界观「咲く」是游戏整体主题，不是真乃个人的表达特征

# 八、表达DNA核心特征总结

1. **「ほわ」三件套**：拟声词开场（ほわっ）+省略号思考（……）+促音收尾（っ）——声音先于意义
2. **无长音、无方言、无粗口**：标准语+礼貌体+拟声词的纯净组合
3. **不确定性标记密度高**：「〜かも」「〜のかな」柔化一切判断——她几乎不断言
4. **鸟比喻单一系统**：所有即兴描述滑向鸟/花/天空——天然呆的本质是「自然滤镜」
5. **感谢/道歉/努力三角**：ありがとう336+すみません83+頑張182——她的语言世界是感恩与努力
6. **「むんっ」决心拟声词**：自我打气的固定方式——「頑張るよ、むんっ」
7. **省略号是她的呼吸**：8624次省略号——未说完的话、犹豫、思考全在里面
8. **称呼体系**：プロデューサーさん（519）+灯織ちゃん（493）+めぐるちゃん（478）——她的世界由P和单元成员构成
