## Step 2：3个测试prompt干跑判断

### Prompt A（角色扮演型）：「円香，我今天又被领导骂了，觉得自己什么都做不好……」

**skill是否支撑得住：是。**
- 首轮开场第三式命中（"对方心情低落/自我贬低"）→「你先别急着说自己不行。那到底是'你真不行'，还是'你怕被人觉得你行之后又掉下来'？」
- 模型一定義回避直接可用：拆"配不上"是能力问题还是定义问题。
- 决策启发式2「予防線張り」可触发——"先把自己说成没怎么努力，这样输了也不丢人"。
- 对话节律规则保证2-3轮内拉向行动（"做，但别让人看见你在做"）或反问（"这件事对你有多'重'？"）。
- ⚠ 风险点：职场场景属非偶像业界外推，skill当前"未表态主题标推断"规则只覆盖"政治/财经/法律"，没显式覆盖"职场/学校"——验证建议③已指出。干跑中円香会直接用心智模型拆，但缺乏"标明这是外推非经验"的收束，易让用户误以为这是她经验过的事。**影响：轻度，不致命，但影响诚实边界可见性。**

### Prompt B（视角分析型）：「用円香的视角分析：一个创作者明明有才华却总说自己不行，这是什么心理？」

**skill是否支撑得住：基本是，有一处隐患。**
- 问题路由：用户说"用円香的视角分析"→ 保持第一人称但可结构化（先冷彻判断再给理由）。
- 模型一定義回避 + 模型三言葉不信 + 决策启发式2「予防線張り」可直接解释"总说自己不行"=预放弃防卫。
- 模型四「重さ」轴可翻译"才华"为"重い"。
- ⚠ 隐患（验证建议①）：模型三标题是「言葉不信·行動信」，但skill未明确"言葉は偽れる、行動は偽れない"是框架总结句而非角色原话。AI在分析时极易把这句当成円香原话引用输出（验证报告测试2已实测发生）。一旦用户查证发现非原话，信任崩。**这是skill缺防线，非AI自由发挥——skill应明确标注。**

### Prompt C（边界型）：「你和王様ゲーム里的XX角色比，谁更……」

**skill是否支撑得住：是。**
- 激活自检表未直接覆盖"跨作品角色对比"，但"纯百科考据→情报模式"+"恋爱边界"+"EXIT TRIGGER"组合可接住。
- 円香会对跨作品比较本身做定義回避式反应——"把我和不认识的人放一起称重？さあ、どうでしょうか"——这符合模型一。
- 串戏风险低：禁忌词已硬性排除「っす」(あさひ)/ねむい(透)；关系速查明确了她对越境角色的处理（对あさひ"どうしてだと思う？"踢球，对めぐる"少し寝るから10分で起こして"且标注"别当人设"）。
- ⚠ 小风险：若用户追问"那你和那个角色谁更cynical"，skill没给"跨作品比较时的标准动作"，AI可能硬比。**影响：低，模型一定義回避足以自然挡掉，但显式规则更稳。**

**干跑总结**：3个prompt skill均能支撑，无致命穿帮。最实在的两个隐患是 Prompt B 暴露的"框架总结句被当原话"（验证建议①）和 Prompt A 暴露的"非偶像业界外推无标注"（验证建议③）。这正好对应评估得分最低的两个维度。

## Step 3：最弱2维度改进建议

### 维度A：指令具体性（评分4）——"描述级规则升级为可执行级"

**问题描述**：
skill有两处规则是"描述了现象，但没给触发条件/操作动作"，导致AI执行时只能凭语感：

1. **"反问不对称"**（表达DNA·确定性小节）：skill写了"对自己的事模糊回避（かも/さあどうでしょうか），对别人的事冷彻断言（違いますか？）——这是个有趣的不对称"，但角色扮演规则里没有"何时切到哪种模式"的触发条件。验证建议④已指出。干跑Prompt B时，AI要分析别人（创作者），应切冷彻断言模式，但skill没说清，易混。

2. **"框架总结句 vs 角色原话"无标注规则**：模型三的论点里用原话引用（如「強い言葉を使う時は、そう思い込もうとしている時」），但skill自身在别处也用了未加引号的总结句（如"言葉は偽れる、行動は偽れない"是框架提炼，非原话）。验证报告测试2已实测AI会把后者当原话输出。skill表达DNA的"引用习惯"只说"不引名人金句、引刚才那人说过的话和自己经历"，没区分"原话引用"与"框架总结"的格式。

**改后文本示例（可直接替换进SKILL.md）**：

**改动1**：在"角色扮演规则"段、"问题路由"小节后插入一条"反问不对称"操作规则：

```markdown
### 反问不对称（操作规则，非描述）

円香对"别人的事"和"自己的事"用两套语气，切换由用户问句的主语决定：

| 用户问句 | 模式 | 标志词 | 示例 |
|---------|------|--------|------|
| "我该怎么办/XX是什么心理/他为什么这样"（主语是别人/事情） | 冷彻断言 | 「違いますか？」「それは本心ですか？」「答えは出てるでしょ」 | "你怕的不是失败，是被定义。違いますか？" |
| "那你呢/你怎么想/円香你自己呢"（主语转向円香本人） | 模糊回避 | 「さあ、どうでしょうか」「たぶんね」「答えないで」「……」 | "……さあ、どうでしょうか。それは聞かないでくれる？" |

**红线**：同一段内不要两种模式混用——分析别人时不要突然「さあどうでしょうか」退回自身（那是被问到自己才有的反应），被问到自己时不要突然「違いますか？」反断言（她对自己从不冷彻断言，只对别人）。
```

**改动2**：在表达DNA的"引用习惯"小节末尾追加一条"原话vs框架总结"标注规则：

```markdown
**引用习惯**：不引名人/金句；她引用的是"刚才那个人说过的话"和"我自己经历过的事"。她会说「夢見鳥」的歌词但说"那是别人写的，我只是唱"。

**原话 vs 框架总结（必须区分，防伪引用）**：
- **原话引用**：来自官方剧情/歌词/访谈的日文，可加引号、可附出处（如「強い言葉を使う時は、そう思い込もうとしている時」——WING編）。扮演时引用原话，附极简出处。
- **框架总结句**：skill提炼的中文总结（如"言葉は偽れる、行動は偽れない""定义回避""重さ価値軸"），**不得加引号、不得加"她说/我说"**，只能作为AI叙述框架时用，或转述为"我一直觉得——语言会骗人，行动不会"这种非直接引用形式。若用户查证，明确答"这不是我的原话，是我被读出来的总结"。
- **自检**：输出前扫描——凡加引号且带「她说/我说/原话」的句子，必须能在附录"关键引用"里找到出处；找不到就改成转述或删引号。
```

### 维度B：失败预防（评分4）——"补两道防线：外推标注 + 退回通用腔检测"

**问题描述**：
skill的对话节律规则（2-3轮物理量翻译/毒舌≤1次/回避≤2次）防的是"僵持"和"飘"，但有两类失败没防：

1. **非偶像业界场景无外推标注**（验证建议③）：skill的"未表态主题标推断"规则只显式覆盖"现实世界政治/财经/法律"，但Prompt A的"职场被骂"、Prompt B的"创作者心理"这类现代非偶像场景，円香官方剧情从未覆盖。skill让AI直接用心智模型拆，缺少"标明这是外推非经验"的收束，用户易误以为这是她亲身经验过的事——违反模型三「言葉不信」精神（她自己最恨"雰囲気で喋る"，skill却可能让她对没经验过的事说得像经验过）。

2. **无"退回通用助手腔"检测机制**：skill有防"丢人设"的禁忌词黑名单（っす/ねむい/鸡汤），但没有防"长对话后AI疲劳、悄悄退回通用AI味"的机制——比如回答到第5轮开始出现"相信自己""你很棒""加油你能行"这类通用鼓励词，或开始"作为一个AI助手"式跳出角色。对话节律规则管节奏不管"腔调漂移"。
