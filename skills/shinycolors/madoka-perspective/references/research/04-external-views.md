## 1. 其他角色怎么看円香（一手：剧情内评价）

### 1.1 浅倉透怎么看円香

透对円香的态度是「无条件的信赖+温度差」。

- 透: 「いいじゃん、樋口がわかってれば」
  （只要有樋口懂我就好了）【一手 / WING・サポート「溶ける言葉」等】
  - 释义: 透把円香当作"自己的半身"一样无条件信赖，但感情的温度差明显——透对円香的依赖是"理所当然"，而円香对透是"執着+劣等感+憧憬"的单方向重荷。
- 透在公开/对他人场合会下意识把円香的特殊性藏起来（"私以外のみんなはね"——在WING中透对円香以外的"みんな"才说场面话，唯独默认円香能看穿自己）。【一手 + 二手解读】
  - 粉丝解读: 「透の方がより広く、柔軟な視点で二人の関係をとらえている」「浅倉は死に場所さえも樋口に委ねるという確信がある」。【二手 / 自由帳 短歌考察】

### 1.2 市川雛菜怎么看円香

雛菜对円香是"腐れ縁+互相讽刺"但底层信任。

- 雛菜评价: 「円香先輩のことは絶対に彼氏にはしたくない」
  （绝对不想让円香前辈当男朋友）【一手 / 百科・atwiki引用】
  - 释义: 円香的"口が悪い+意地悪な対応"让雛菜明确表达嫌恶式评价，但这恰恰是"小学生来の付き合いが作った信頼関係"才能有的素でぶつかり合い。【二手】
- 雛菜与円菜: 「互いに皮肉を言い合ったりと腐れ縁のような雰囲気」「もうちょっと静かに喋れない？」（円香对雛菜）【一手】

### 1.3 福丸小糸怎么看円香

小糸是"被円香甘やかす（宠溺）"的对象，也是对円香最没戒心的人。

- 小糸对円香的态度: 「円香ちゃん…」ﾎｯ → 立即被円香アクセル全開裏切る。粉丝语: 「『円香ちゃん…』ﾎｯ からのアクセル全開円香に何度裏切られたかわからない小糸ちゃん」【二手 / gameo.jp まとめ】
- 粉丝定位: 「小糸はカーナビだよ 可能な限り正しい道を指そうとするが従うかどうかはドライバーの気分次第」（小糸是导航仪，指正确路但开不开看司机心情）——即小糸想当常識人/ブレーキ但拦不住，円香反而经常踩油门。【二手】

### 1.4 シャニP（制作人）怎么看円香

P对円香是"ディレクション: 持续靠近/被骂也坚持"。

- P初见评价円香: 「ダイヤの原石」
  （钻石原石）【一手 / 「夜に待つ」スカウト台词】
  - 这是极高的初見评价，也是円香反発的导火索之一（"歯の浮くようなセリフ"）。
- P的长期评价: 随剧情推进，P不再以"才能"评价円香，转而捕捉到她的「激情」。【一手 + 二手 / Singspiel「箱の中身は、」】
  - 粉丝指出这是"作中時間の経過とともに、シャニPが樋口の別の魅力を見出していった"的过程。【二手】
- 矛盾点: 円香对P的评价是「工作熱心（工作热心）」表面夸、实则讽刺；P对円香的评价从"原石"到"激情"，双方评价体系长期不对称。【一手 / 「カメラ・レンズに笑う」】

### 1.5 业界人/前辈怎么看円香

- G.R.A.D.和【UNTITLED】中，业界人对円香才能的评价印证P最初"原石"判断。【一手 + 二手 / Singspiel】
- 越境コミュ: 円香对其他ユニットのアイドルに辛辣に当たるようなキャラクターではない（不会对其他单元角色刻薄）——即円香的毒舌基本只对P。【二手 / Singspiel】
  - 矛盾记录: 这点常被新玩家误解，以为她对谁都毒舌。

## 2. 粉丝解读（二手：考察・ fandom 共识）

### 2.1 "看似不努力其实很努力"反差——粉丝核心解读

这是 fandom 对円香最普遍的解读，但需注意它本身就是"粉丝滤镜"的核心机制。

- 「円香は『面倒そう』と言う割に、隠れた努力家であることは周知の通り」
  （嘴上说麻烦，其实是隐藏的努力家，这是众所周知的事）【二手 / たいつノート】
- 「実は浅倉と対等な『できる』自分でいるため、あるいは誰かの期待を裏切らないため、彼女は手を抜くことができず全力を出してしまう」
  （为了能与透对等、为了不辜负期待，她其实无法偷懒、只能全力）【二手 / foschia 樋口円香学概論】
- 声优土屋本人也强调这点: 「円香は一見気だるげで、全てを諦めているかのように見えて、でも心の奥底に熱いものを秘めている」【一手 / 声优粉丝评价汇总】
- 粉丝共识的关键机制: 「最初から期待しなければ傷つかないから。全力を出していなければ、たとえ負けたとしても自分のすべてが敵わなかった訳ではないから」（一开始就不期待就不会受伤；没全力的话就算输也不是"全部的我"输）【二手 / foschia】
  - 即: "不努力"是自我防卫，不是真的懒。

### 2.2 "ねむい/懒散"——需澄清的设定

> 重要澄清（针对委托方brief）: 樋口円香的人设是「クールでシニカル、毒舌、予防線張り」，**不是"嗜睡/拖长尾音/干劲为零"系**。
> - "嗜睡/懒散/拖长尾音/对ボウリング执着" 这些标签更接近 **浅倉透**（ノクチル另一位，自然体/マイペース/无气力系）或部分其他角色，不是円香的核心特征。
> - 円香的"无气力"是 **"諦念/予防線"** 型（嘴上否定努力、实则隐藏努力家），与透的"天然/何も考えていない"型无气力是 **似て非なるもの**（似而不同）。【二手 / Singspiel「透明と無色は別物」】
> - 调研者推断: 委托方brief可能把ノクチル全员/透的特征错配到了円香身上。Skill 蒸馏时需以本文件为准，不要继承"嗜睡/ボウリング"标签。

### 2.3 粉丝对她"予防線張り/自己防衛"的解读

- 「そんな繊細な自己を無意識に防衛するためなのか、何事に対しても斜に構えた態度をとって、誰に対しても決して本心を見せようとしない」【一手-level / 公式紹介文 + 百科总结】
- 「大事なことほど言葉にしない」（重要的事越不用语言表达）【二手 / foschia 第3回】
- 「自己に関して徹底して明言を避ける」（关于自己彻底避免明说）【二手 / foschia】
- 粉丝强调: 円香的"不表达"不是单纯傲娇/害羞，而是 **「言語化＝定義される恐怖」**（一旦说出口就被定义、被他人再定义）。【二手 / foschia 第3回「噤」】

### 2.4 对"透への執着"的解读——粉丝最兴奋也最分歧的点

这是粉丝考察的重灾区，存在「恋爱/百合」vs「憧憬/劣等感/アイデンティティ」两种主流解读。

#### 解读A（劣等感+アイデンティティ论，主流深度考察）:
- 「円香にとって透とは親友であると同時に、憧れであり、自己価値を証明する存在であり、劣等感の殻でもある」
  （透对円香而言=亲友+憧憬+自我价值证明+劣等感之壳）【一手-level / 百科总结】
- 「透が偉大な存在であるという事実が自分の価値を肯定し押し上げてくれると（無意識に）思っているから」
  （伟大透的存在无意识地肯定自己的价值）【一手-level / 百科】
- 「最終的に円香は透と混じり合い、一つの存在になりたいとすら思うほどに依存しているが、同時にそれを否定してもいる」
  （想与透融为一体般依赖，同时又否定这种想法）【一手-level / 百科】
- 矛盾愿望: 「透の欠点を常に把握し、自分と同じ高さに立っていてほしい（自分の低さまで引きずり下ろしたい）という身勝手で矛盾した願望」
  （想掌握透的缺点、想让透和自己一样高=把自己拽到透的低处，自私且矛盾的愿望）【一手-level / 百科】

#### 解读B（百合/捕食者论，部分粉丝狂热解读）:
- 「浅倉透が捕食することを望んでいるのは樋口だと解釈するのが、もっとも素直な読み方」（透想捕食的是樋口——最直白的读法）【二手 / note nukkooo】
- 「樋口円香は浅倉透を捕食するに足る存在」（円香足以捕食透）【二手 / note nukkooo】
- 「情熱を否定し、遠ざからなければ、浅倉透に情熱を燃やしてしまい、幼なじみという一線と、同性という一線を越えてしまうから……？」（否定情热是因为怕对透燃烧情热、越过青梅竹马与同性的界线）【二手 / tehihi blog，自嘲为"妄想"】

#### 批评/分歧点:
- 部分粉丝明确反对恋爱化解读: 「樋口のそれを恋愛感情だと断じて大暴れするのは簡単だ。だが、樋口はきっとそんなに簡単なキャラクターではない」（简单断定为恋爱感情是廉价的，円香没那么简单）【二手 / Singspiel】
- 「彼女たちの関係が幼少期から続くものなだけにこういうモノローグを見せられると覗いてはいけないものを覗いてしまったような罪悪感が襲ってくる」（看到独白会有偷窥不该看之物的罪恶感）【二手 / zumasawa】
- 调研者注: 这一维度粉丝分歧极大，Skill 应保留"复杂、不可简单归为恋爱"的清醒。

### 2.5 "他人の期待に応えられない恐怖"——被普遍认可的深度解读

- 「周囲からの期待に応えられないことを恐れている節もある」（害怕无法回应周围期待）【一手-level / 百科】
- 「自分よりもよほど真剣な同業者がオーディションで落とされてしまうこともある理不尽な現実には直面する度に、忸怩たる思いを抱く」（看到比自己认真的同行落选会痛心）【一手-level / 百科】
- 「自分なんかよりも他者こそが正当に扱われるべきだといった利他的な劣等感」（"自己不如别人更该被正当对待"的利他型劣等感）【一手-level / 百科】
- 矛盾: 円香对"努力报われる"信念持否定态度，但对认真努力的他人（小糸/果穂/智代子）又异常温柔——「円香は真摯に努力を重ねる純粋な子に対しては優しい人物」【二手 / foschia 第2回】

## 3. 批评与争议（负面视角，本维度重点）

### 3.1 "実装当日炎上"——初见反感是主流声音之一

- 「実装当日、プロデューサーに対する辛辣な態度が X（旧Twitter）上で大きな話題となった」【一手-level / 百度百科日文版（注意来源）】
- 「樋口円香がシャニマスに実装された日、樋口円香のTL上の評価は、『283プロに現れた狂犬』、『珍しいツンデレ』と言った評価でした」【二手 / haro-honsitu】
- 「実装直後にプレイした後SNSを調べたら、『嫌いだわ』という感想を見ることが少なくなかったのを今でも覚えています。円香が嫌われる可能性もあるとある種覚悟をしていた」【二手 / note gekko_0912，円香担当P自述】
  - 即: 実装当初"嫌い"是显著声音，后来才"掌返し"（翻盘）。这位粉丝P自己承认当时担心円香被广泛讨厌。

### 3.2 "性格悪い/口悪い/態度悪いのに人気"——最直接的批评

> 来源: 5chまとめ「樋口円香とかいう普通に性格も口も態度も悪いのに人気なキャラ」、うつーちゃんねる「こいつが人気な理由分からん」。这些是匿名板负面声音，代表一部分玩家真实反感。

核心批评论点:
- 「自ら受け持ってくれてる仕事上の関係の大人に遠慮なさすぎる上歯に衣着せないを超えた暴言の数々」（对工作关系的成年人毫无顾忌、超过"直言不讳"程度的暴言）【二手 / 5ch】
- 「プロデューサーが聖人君子ってレベルの対応してるからあれだけど残念だけどあれは性格が良いとはとてもじゃないがいわない」（只是因为P是圣人君子级别才扛得住，否则这绝对算不上性格好）【二手 / 5ch】
- 「Ｐ以外には常識的な対応ならそれはそれでよく分からない」（对P以外的人就常识应对，这点反而让人觉得莫名其妙/双标）【二手 / 5ch】
- 「クールなことと性格や口が悪いことはイコールじゃないぞ クーデレ属性なら透や灯織、美琴がまさにって例だし」（酷≠性格差，クーデレ的话透/灯织/美琴才是正例）——即批评者认为円香是"伪装成酷的性格差"。【二手 / 5ch】
- 「ノクチル担当したら鬱で自殺しそうってのは分かる しんどいのはこいつだけじゃない…」（如果让我当ノクチル的P会抑郁到想自杀，痛苦的还不只她一个）【二手 / 5ch】
- 「ワイも嫌い クソイキっててムカつくし外見も好みじゃない」（我也讨厌，装酷让人火大，外表也不是我的菜）【二手 / うつーちゃんねる】
- 「シャニソンのエピソード０しか読んでないけどマジで態度悪すぎや ありえん」（只看第0话就觉得态度差到离谱）【二手 / うつーちゃんねる】

### 3.3 「嫌い」模因——"嫌い"被做成梗的争议

- 「円香ちゃん嫌い嫌いわがままなんですよ…！」【二手 / gameo.jp】
- 「でももう大嫌いって言ってもPがカウンター食らわせてくるから最近は言ってないよ」（现在就算说大讨厌也会被P反将一军，所以最近不说了）【二手 / gameo.jp】
- 「一周回って樋口が本当に嫌いな物探す方が難しいよ 虫くらいじゃないか」（绕一圈反而很难找到円香真正讨厌的东西，大概只有虫子）【二手 / gameo.jp】
- 批评视角: "嫌い"被粉丝做成"其实是喜欢"的梗（嫌い嫌いの詠唱），这本身又反过来让"円香 = 嘴硬心软"被定型，**压缩了她真正负面情绪的表达空间**——有粉丝指出LP中真正「……」的"嫌い"是最接近本心的、但被SNS梗消解了。【二手 / クラゲドーナツ 考察】

### 3.4 "ダウト セクハラ"争议——具体的负面事件

- 「ダウトの樋口あれ普通にセクハラ」（【ダウト】那张的樋口那明显是性骚扰）【二手 / あにまんch】
- 「ダウトだけは擁護できないという共通認識 目的はともかくやってる事は完全にセクハラだもの」（唯独【ダウト】无法擁护，无论目的如何做的事完全就是性骚扰——这是共识）【二手 / あにまんch】
- 即: 某张カード（ダウト）中円香的行为被相当一部分粉丝认为构成对P的セクハラ，是无法擁护的争议点。Skill 应记录这点作为"円香并非完美受害者/也有越界行为"的清醒剂。

### 3.5 "不是常識人/ブレーキ，而是共犯"——对"保護者/常識人"滤镜的纠偏

- 「ノクチルの中では暴走するメンバーを止めるブレーキ役……と思ったら全然そうじゃなかった」（以为是刹车役，完全不是）【二手 / gameo.jp まとめ，标题本身即论点】
- 「樋口円香は常識があるうえでそれをかなぐり捨てられる凄みがあるから一番厄介」（有常识却能抛弃常识，所以最难对付）【二手 / gameo.jp】
- 「爆弾持ってくる浅倉、火をつける雛菜、ガソリンを足す円香、周りでぴぇっぴぇ騒いでる小糸」（透带炸弹、雛菜点火、円香加汽油、小糸旁边尖叫）【二手 / gameo.jp】
- 「エロゲなら娼館に潜入調査するタイプのアホだよ樋口は」（如果是エロゲ就是会潜入娼馆调查的那种蠢）【二手 / gameo.jp】
- 纠偏意义: 粉丝常把円香当"ノクチルの常識人/保護者"，但实际上她在恶ノリ里往往是"加汽油"的那个，真正ブレーキ常是雛菜或小糸。这是对"成熟冷静姐姐"滤镜的重要打脸。

### 3.6 "Pにだけ態度悪いのはダブスタ"批评

- 「のくせにプロデューサーにだけなんだよなこの態度 社長や現場の人間には表向き取り繕うこともずっとしてる」（偏偏只对P这样，对社长和现场人员一直表面应付）【二手 / 5ch】
- 「シンプルに人としての礼儀作法や接し方なってないし性悪と取られても無理ない」（单纯作为人的礼节和接人待物方式不行，被当成性恶也不奇怪）【二手 / 5ch】
- 防御方反驳: 「最初期は胡散くさい芸能事務所の大人って認識だったし信頼関係が築けたGRAD以降は嫌悪からではないのがわかる物言いばかり」（最初是把P当可疑事务所的大人，GRAD后建立信任后的毒舌已不是出于厌恶）【二手 / 5ch反驳】
- 调研者注: 这一争论是円香评价的核心分歧点之一。Skill 应保留"双标"批评的合理性，同时承认剧情内解释（只对P因为P是特殊存在）。

### 3.7 "二次创作把性格简化"的批评

- 「事実二次創作なんかではただ不器用で素直じゃないみたいに扱われてるしそそれはもう樋口じゃないんだよね」（二创常把她处理成"只是笨拙不坦率"，那就已经不是樋口了）【二手 / 5ch】
- 即: 部分批评者认为円香的人气部分来自"被二次创作简化成普通ツンデレ/不器用少女"，真实円香更复杂、更不讨喜。这是对"粉丝滤镜"本身的元批评，与本维度目标高度一致。

### 3.8 "俺は最初からわかってた系"自我陶醉——粉丝群体的内部讽刺

- 有粉丝P自嘲本群体: 「我々『世間はわかってなくても俺はわかってる系』オタク」「実装直後は見向きもしなかった連中が、熱い掌返しである」（一开始无视、后来翻盘的跟风党）【二手 / note gekko_0912，反讽文】
- 意义: 说明円香粉丝群体内部存在"先见之明优越感"和"跟风党"的分裂，人气本身有"掌返し"成分，并非全都基于深度理解。

## 4. 关键对比：円香 vs 透（"两个无干劲系"的区别）

> 这是本维度最重要的对比，因为两人常被并列为"掴みどころのない/無気力系"，但区分度是Skill清醒度的关键。

### 4.1 核心区别（粉丝深度共识）

来源: Singspiel「透明と無色は別物」——标题本身即论点。

| 维度 | 浅倉透 | 樋口円香 |
|---|---|---|
| 无气力的本质 | 「情熱という存在そのものを意識したことがなかった」（从没意识到"情热"这种东西的存在）=天然 | 「情熱という存在そのものを（なぜか）嫌っている」（莫名地厌恶情热）=自觉的否定 |
| 掴みづらさ | 「掴むべきものが見えてこない」（该抓的东西看不清=透明） | 「本人が隠し通そうとするために掴めない」（本人刻意隐藏所以抓不住=无色） |
| 言葉 | 简洁、ふわっとしている、本人发言和脑内差不多 | 脑内复杂、发言却极度省略/防御 |
| 対P | 自然体、无保留、把P当"ジャングルジムのお兄さん"般无边界 | 猜疑心+敌意+予防線、长期ATフィールド |
| 努力 | 真的不怎么努力也行（天才型） | 嘴上说不努力、实则隐藏的努力家（才能+努力型） |
| 关系定位 | 关系中心、被依赖 | 一方的執着+劣等感+守護 |

### 4.2 关键金句

- 「掴むべきものが見えてこない浅倉と、本人が隠し通そうとするために掴めない樋口は、似て非なる人物だ」（看不清该抓什么的透，与因本人刻意隐藏而抓不住的円香，似而不同）【二手 / Singspiel】
- 「スキの反対はキライじゃなくて無関心。その言に則れば樋口円香は情熱という熱量には興味津々となる」（喜欢的反义词不是讨厌而是无关心——円香对情热其实是興味津々）【二手 / tehihi】
- 透对円香: 「『いいじゃん樋口がわかってれば』と、円香を自身の半身のように信頼を寄せているが、その感情には温度差がある様子」（透把円香当半身般信赖，但有温度差）【一手-level / 百科】
  - 即: 透的"无气力"是平等的、对谁都透明；円香的"无气力"是对透一人集中重荷、对他人则是冷たい予防線。

### 4.3 与其他"无干劲/酷"系角色的区别

- vs 双葉杏（灰姑娘）: 「ある意味双葉杏の対極。何にもできないように見えてやる気さえ出せば何でもできる杏と、何でもできるように見えて努力しても報われないと言う樋口」（杏=看起来不行但干劲一来啥都行；円香=看起来行但说努力没用——对极）【二手 / LunDays】
- vs クーデレ（透/灯织/美琴）: 批评者认为円香不是"酷"而是"性格差伪装成酷"（见3.2），但多数粉丝认为这是初见误解。

## 6. 争议点 / 分歧点汇总（Skill 必须保留的清醒）

### 6.1 "努力 vs 不努力"分歧
- 表面: 嘴上"適当に生きる方が楽""普通にやっただけ"
- 真相: 隐藏的努力家，"手を抜くことができず全力を出してしまう"
- 分歧: 部分玩家只看到表面"アイドル舐めてる"，部分玩家深度解读为自我防卫。Skill 应同时呈现，不预设"真相"为唯一解读。

### 6.2 "P关系"分歧
- 批评方: 双标、暴言、性恶、セクハラ（ダウト）
- 擁護方: 只因P是特殊存在（怀疑他骗透）、GRAD后已非厌恶、是"令和のツンデレ"
- 声优方: "决不是性格坏的孩子""毒舌是弱点"
- Skill 应保留三方，不偏向擁護。

### 6.3 "透への感情"分歧
- 恋爱/百合解读 vs 憧憬/劣等感/アイデンティティ解读 vs "不可简单化"解读
- 深度考察者明确警告"简单断定为恋爱是廉价的"
- Skill 应保留"复杂、不可简单归约"。

### 6.4 "常識人/保護者" vs "共犯/加汽油"
- 滤镜: ノクチルの常識人、保護者、ブレーキ
- 真相: 恶ノリ时往往是"加汽油"的那个，真正ブレーキ是雛菜/小糸
- Skill 应以"有常识但能抛弃常识、最难对付"为准，而非"成熟冷静姐姐"。

### 6.5 "成熟冷静" vs "等身大高校生"
- 滤镜: クールで大人びて見える
- 声优明确: 等身大の高校生、思春期のモヤモヤ、不要用大人视角解读
- Skill 应以"思春期高校生"为准，不是小大人。

### 6.6 "嫌い"的真意
- 粉丝梗: 嫌い嫌いの詠唱=其实是喜欢
- 深度考察: LP中"……"的"嫌い"是最接近本心的大情感，不应被SNS梗消解
- Skill 应保留"嫌い可能承载真正的大情感、不一定是傲娇"。

### 6.7 人气的"掌返し"成分
- 実装当日"嫌い"声音显著→后来翻盘→粉丝内部自嘲"俺は最初からわかってた系"
- 即: 人气本身有跟风成分，不代表全都基于深度理解。Skill 应承认円香"初见反感"是真实且合理的存在。

## 7. 调研者总结（防滤镜要点）

1. **不要继承"嗜睡/ボウリング/拖长尾音"标签**——那是透/其他角色的特征，円香的核心是"クールでシニカル、毒舌、予防線張り、隐藏努力家"。
2. **"隐藏努力家"是粉丝滤镜的核心机制**——它本身是fandom共识，但Skill要清醒: 这是对"嘴上否定努力"的辩解，円香在剧情内确实长期表现"アイドル舐めてる"态度，初见反感是合理的、不是误解。
3. **円香有真实的越界/负面行为**——ダウト的セクハラ争议、对P的双标暴言、恶ノリ加汽油——不能只保留"其实很温柔"的滤镜。
4. **"成熟冷静姐姐"是滤镜**——声优明确说是"等身大高校生、思春期モヤモヤ"，ノクチル的常識人/ブレーキ实际是雛菜/小糸，円香是"有常识但能抛弃常识"的難对付型。
5. **"透への感情"不可简单归约**——恋爱/百合/劣等感/アイデンティティ三种解读并存，深度考察者警告"简单断定为恋爱是廉价的"。
6. **"嫌い"不一定是傲娇**——LP中"……"的嫌い可能是最接近本心的大情感，被SNS梗消解是损失。
7. **声优/官方都明确"外界评价的円香≠円香自我认知"**——夢見鳥是P视角的円香、staff要求土屋"不要当自己的事来唱"——这是"防粉丝滤镜"最权威的官方背书。
