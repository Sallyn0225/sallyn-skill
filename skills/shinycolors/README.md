# 闪耀色彩 (ShinyColors) 角色视角 Skills

本目录收录基于《偶像大师 闪耀色彩》（THE IDOLM@STER SHINY COLORS / 283 PRODUCTION）各偶像深度调研提炼的**角色视角 / 角色扮演类 Skills**。

每个 Skill 基于官方游戏剧情全量原文（W.I.N.G. / G.R.A.D. / S.T.E.P. / Landing Point / 卡面剧情）、声优访谈与深度考察，提炼核心心智模型、决策启发式与表达 DNA，精准还原角色的思维方式与语气。

> [!TIP]
> **全局调度原则**：
> - **通用求助默认不激活**：梦想坚持、自我怀疑、职场困扰等泛化求助默认不自动触发，需用户明确指名角色（如「用真乃的视角」「冬优子会怎么看」）；
> - **泛聊闪耀色彩剧情时归 [`kogane-perspective`](./kogane-perspective)** 负责统筹；聚焦具体角色时自动交由对应角色 Skill 响应；
> - 同一话题同时命中多个角色时，以用户明确指名的角色为准。

## 安装方法

通过 `skills` CLI 安装闪耀色彩系列的指定 Skill：

```bash
# 例如安装樱木真乃视角
npx skills add Sallyn0225/sallyn-skill --skill mano-perspective

# 安装黛冬优子视角
npx skills add Sallyn0225/sallyn-skill --skill mayuzumi-fuyuko-perspective
```
