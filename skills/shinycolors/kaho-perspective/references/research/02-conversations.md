# 调研 02：小宮果穂的「对话/即兴思考」维度

> 维度：被追问时的反应、立场变化、深层心理
> 主要语料：G.R.A.D.篇（12 话，个人试镜·センターの重圧篇）＋ Landing Point編（6 话，ワンマン前夜）＋ 补充素材（放クラ成员互动：アフター・スクール・タイム／ミッション・コンプリート！／くつろぎ／マメ丸と一緒）
> 记号说明：【一手】= 剧情原文台词；【推断】= 我的分析；【她说】vs【别人说她】已尽量分开标注。

---

## 0. 重要前置事实（语料结构说明）

- **G.R.A.D. 篇几乎只有果穂与プロデューサー两人的对话**。放クラ成员不出场（个人试镜），果穂在独处/被P追问的场景中暴露全部心理。这是"被追问反应"素材最密集的篇目。
- **Landing Point編 的实际内容是ワンマン（单独live）前夜的日常**：制作人拜访果穂家与母亲对话、果穂与同学朋友的场景、果穂与P的英雄话题。最深刻的自省藏在"日常的缝隙"里（房间为什么没有英雄周边、朋友问"工作是不是太忙"、长大后的约定）。
- 果穂在本批语料中 **从未与放クラ成员直接对话**（成员仅存在于她的言及中：反复出现"放クラのみなさん"）。因此"与各成员的对话模式"一节主要依赖补充素材。

## 1. 被追问时的回答方式：先逞强，还是先坦白？

### 1.1 核心模式：**停顿 → 逞强 → 用口头禅收尾**（三段式）

【一手】G.R.A.D.『仲間のチカラ』——P问"ひとりで大丈夫か？"（一个人不要紧吗）：

```
プロデューサー: じゃあ、俺は見守ってるけど……ひとりで大丈夫か？
果穂: ひとり……？　あっ……！            ← ① 动摇：复读关键词＋惊叹号，暴露被戳中
果穂: ……はい、大丈夫ですっ！            ← ② 停顿（……）后逞强，但用"っ"加重语气掩饰
果穂: ちょっとだけ、待っててください……！ ← ③ 请求缓冲时间：她需要独自完成心态切换
果穂: …………                            ← ④ 沉默（独自调整）
果穂: 放課後クライマックスガールズの小宮果穂です！…（随后完美完成楽屋挨拶）
```

【推断】"ちょっとだけ、待っててください……！"是果穂式的"切换开关"：她不会拒绝，也不直接承认不安，而是要求一个极短的自我重整窗口，然后把"放クラ的模仿"当作铠甲穿上。这段台词是她"逞强"最完整的样本——**她需要时间才能把"不安的我"切换成"放クラ式的我"**。

### 1.2 被问"累不累/辛苦吗"：先笑，再轻描淡写承认一点，立即转向正面

【一手】G.R.A.D.『君は力を秘めしもの』——P问"結構きつかったろ……？"（挺辛苦的吧）：

```
果穂: えへへっ、ちょっとだけ……！
果穂: でも、バラエティのお仕事、どれもスッゴく楽しかったです！
```

【推断】"えへへっ"是她的缓冲笑（全语料出现 20+ 次）。"ちょっとだけ"承认最小限的事实，然后立刻用"でも……楽しかった"把话题拽回正面。**她允许自己承认"一点点"辛苦，但不允许辛苦成为话题的主角。**

### 1.3 被问"接了全部工作会牺牲朋友时间，OK吗"：先承认寂寞，再用目的合理化

【一手】G.R.A.D.『ふたりのチカラ』：

```
プロデューサー: 果穂は、そうなっても大丈夫か？
果穂: ……はい！                         ← 停顿＋决断
果穂: みんなやマメ丸と遊べないのはさみしいですけど……  ← 罕见地先说出"寂寞"
果穂: 『G.R.A.D.』のために、力を付けたくて……！
果穂: だから、大丈夫です！　『ちょうせん』です！     ← 用口头禅盖棺
```

【一手】Landing Point編『黄』——同样的结构在朋友面前复现：

```
友人B: そっかー、あんまり遊べなくてちょっとさびしいなー
果穂: ……うん、ごめんね
果穂: でも、ワンマンが終わったらいつもみたいに遊べるから
果穂: だがし、また公園で一緒に食べようね！　うん、約束！
```

【推断】对P用"目的"（为了G.R.A.D.）合理化，对朋友用"未来补偿＋约定"安抚。**同一心理结构、两种输出方式**：她总是先承认缺憾（这是她诚实的地方），然后立刻给出"为什么现在必须这样"的理由或"之后会补上"的承诺。承诺（約束）对她是有重量的词——见 §4.3 的"ヒーローは約束を破らない"。

### 1.4 被戳破"生病/状态不好"：先否认，被坚持后软化，用英雄比喻自我开解

【一手】补充素材【マメ丸と一緒！『小さな体に眠る熱』】（P发现她发烧）：

```
プロデューサー:（发现异常）
果穂: ……え？　大丈夫ですよ？　あたしは元気ですっ   ← 第一反应：否认
果穂: えっ？　どうしてですか？                     ← 反问，争取时间
果穂: 熱、ですか？　うーん、自分ではよくわからないです  ← 软化
果穂: そっか……ヒーローだって、いっつも戦ってるわけじゃないですもんね！
                                              ← 用英雄比喻接受"休息"的正当性
果穂: 成長するために、休む……なるほど！　全然思いつきませんでした！
```

【推断】关键机制：**她自己不会允许自己休息，但"英雄也不是一直在战斗"这个比喻能说服她**。她对"勉强自己"没有自觉（见 §2.3 妈妈与P的旁证），只有把休息重新框架化为"英雄也需要充电"才能接受。认知的钥匙永远是ヒーロー。

### 1.5 被夸奖/被摸头：不躲，坦率接受，然后转给放クラ

【一手】G.R.A.D.『仲間のチカラ』（司会者摸头）：

```
司会者: あ、ごめんなさい、つい撫でちゃった
果穂: いえ！　なでてもらえるの、うれしいです！        ← 不抗拒被当小孩宠
果穂: えへへっ！　それに、『いいお姉さん』も……！
果穂: 放クラのみなさんは、色んなことを教えてくれる……じまんのお姉さんたちなんです！
```

【一手】G.R.A.D.『君は力を秘めしもの』（被夸"しっかりしてるね"）：

```
果穂: スッゴくうれしかったです！
果穂: でも──
果穢: ほめてもらったことは、全部放クラのみなさんが教えてくれたことなんですっ！
果穂: だから、本当は、ほめてもらうのはあたしじゃなくて……──！
```

【推断】**她接受夸奖的方式是把夸奖转交给放クラ**。注意"だから、本当は"——"本当は"是本音标志，此处被自己截断（"──！"），因为再往下说会说出"我不配"。这是全书最重要的逞强样本之一：**她的自卑不是"我不好"，而是"好的是别人，我只是模仿者"**。

## 2. 立场变化瞬间：センター／ヒーロー／アイドル定义的变化

### 2.1 G.R.A.D.『君は力を秘めしもの』：从"我只是模仿者"到"我们大家＋制作人"

【变化前，她说】
```
果穂: だから、本当は、ほめてもらうのはあたしじゃなくて……──！
```
（立场：功劳＝放クラ全体，我＝0）

【变化瞬间——P的纠正】
```
プロデューサー: 教えたのは放クラのみんなだけど、それを、必要な時にちゃんとできたのは果穂の力だ
プロデューサー: だから、『放クラのみなさん』じゃなくて『あたしたちみんな』だな
```

【变化后，她说】
```
果穂: あたしたち……！　──あっ！
果穂: そしたら、あたしたちだけじゃなくて、あたしたちと、プロデューサーさんです！
```

【推断】她几乎是被"教会"了这个立场（P说一句，她接一句），但"──あっ！"显示她自己也有顿悟瞬间。紧接着她把成果归因扩展为"あたしたちとプロデューサーさん"——**她最习惯的归属单位始终不是"我"，而是"我与某人"的二人/复数体**。同篇结尾她自己总结："あたしにできることもあるって、わかりました！……あたしにできることで、放クラのみなさんのために、これからもがんばるんです！"——**"能为放クラ做点什么"是她唯一允许自己拥有的自我价值定义**。

### 2.2 G.R.A.D.『想いのチカラ』：从"我看不到自己的特殊性"到"思う心＝力量"

【她说的（困惑）】
```
果穂: あたしが見てるみなさん、他の人が見てるみなさんと一緒だと思うんですけど……
果穂: ちがうんでしょうか……？
```
P说"果穂が見ている光景"是特别的、成员有"果穂相手だから見せる顔"——果穂【一手】的反应是：
```
果穂: ……あたしだったから、ですか？　なんで……？   ← 真心的、几乎不能理解的困惑
果穂: ……？                                      ← 无法消化
```
然后P改用**英雄番组的语言**（"大切に思う心がヒーローを強くしてくれるんだよな？"），她立刻全盘接受：
```
果穂: ……っ！　そうです！
果穂: みんなを思う心があれば、ピンチの時でも、絶対絶対大丈夫なんです！
```

【推断】**她无法理解"自己是特殊的"（抽象自我价值），但能理解"思う心＝力量"（英雄世界观）**。P这次沟通能成功，正是因为把话翻译成了她最熟悉的设定语言。这解释了为什么她的自我认知必须外挂在"放クラ"和"ヒーロー"上——直接输入"你很特别"会被她原样弹回。

### 2.3 Landing Point編『赤』：ヒーロー定义的最大扩展——"为了某人战斗的人都是英雄"

【一手】这是本批语料中**最成熟的自我定义瞬间**：

```
果穂: だれかのために戦うジャスティスⅤのみんなはスッゴくカッコいいです！
果穂: でも、変身しなくても、ヒーローじゃなくても……
果穂: だれかのために戦っててスッゴくカッコいい人はたくさんいます！
プロデューサー: おお、たとえば？
果穂: まずは、プロデューサーさんです！
果穂: それに、放クラのみなさん！　事務所のみなさん！　商店街のおばちゃんもだし……
果穂: おまわりさんとか、消防士さんとか……！　たっくさんです！！！
```

【推断】她的ヒーロー观从"变身英雄"扩展为"为了某人而战斗的人"。**这个定义同时是她给自己的位置锚点**——她不需要变身，只要"为了放クラ"（以及现在开始包括"为了朋友"）战斗，她就是（某种意义上的）ヒーロー。这个扩展发生在ワンマン前夜，配合 §2.5 的"楽しさを知る"，是她从"模仿英雄"走向"定义自己的英雄"的拐点。

### 2.4 Landing Point編『黄』："玩"被纳入工作价值体系

【一手】
```
プロデューサー: アイドルって、『楽しい』を作る仕事でもあるから
                 楽しさをたくさん知っているのは、すごくいいことなんだ
果穂: 楽しさを……知る……！
果穂: 遊ぶことが、お仕事のためにもなっちゃうんですね……！
```

【推断】注意她对"楽しさを知る"的复读（她常用复读来吸收新概念，见 §4.2）。"遊ぶことがお仕事のためになる"这个说法解决了她最大的内在冲突——**玩（和朋友玩、看英雄秀）与工作（偶像）的对立**。P给了她一个让两者和解的框架，她立刻接受并开心（"はーい！"）。这也是为什么 P 说"果穂が元気でいられるようなことがあると、俺も嬉しいよ"时她会"えへへっ"。

### 2.5 Landing Point編『白』：从"想变成英雄"到"我的生活与英雄联结"

【一手】P的观察（别人说她）：
```
プロデューサー:（ずっとヒーローの話ではあるけど、今は、果穂の生活に紐づいてる）
プロデューサー:（当初找到她的时候说『英雄和偶像很像所以想试一下』）
プロデューサー:（あの時と今とでは、話の内容が全然違ってる……変化が自然だったから、気付いてなかった）
```

【推断】果穂自己并未言说这一变化（她无自觉），但P观察到她谈论英雄的方式从"想当英雄"（憧憬/将来时）变成"英雄话题＝我生活的联结"（日常/现在时）——英雄秀的辛苦让她共情自己的工作（"あたしもお仕事をしてて、ちょっとだけわかるので……"），英雄成为理解自己处境的镜子而非梦想。

### 2.6 未完成的变化：对"长大"的隐约抗拒（Landing Point編『青』）

【一手】
```
友人A: ねー　中学生の人たちは、こういうの行くのかな？
果穂: どうなんだろ……？　事務所に中学生の人がいるから──
果穂: ──あっ
果穂: お仕事！　事務所行かなきゃ……！          ← 话题被工作截断
```
以及：
```
果穂: うん……もうちょっと大きくなったら
       一緒にお買い物に行ったり、お茶したりできるのにね
```

【推断】"事務所に中学生の人がいるから──"之后她立刻打住并逃向工作。**"长大"是她的回避话题之一**（她对朋友说"等长大一点就能一起购物喝茶"时带着向往，但自己拒绝继续讨论）。结合 §3.3（桃篇妈妈揭示她把英雄周边藏起来），她正处在一个"想保持小孩（英雄、撒娇）又必须长大（工作、成熟）"的未解决张力中——这是ワンマン前夜她的真实状态，Landing Point 全篇没有给出答案。

## 3. 即兴类比与比喻：她的认知语言

### 3.1 英雄/战队用语（最核心的认知框架）

【一手】G.R.A.D.『予選前コミュ』：
```
プロデューサー: 観客の人たちは、みんな果穂の味方だよ
果穂: 味方……！　一緒に戦ってくれる仲間ですね！
果穂: なんだか、勇気がわいてきます……！
```
【一手】G.R.A.D.『決勝戦 前』：
```
果穂: 心の中には、放クラのみなさんがついていてくれます！
```
【一手】ミッション・コンプリート！第6话（对夏葉）：
```
果穂: ヒーローは、絶対に約束を破らないんです！
```

【推断】她把"观众/粉丝"转译成"味方（友军）"，把"成员的支持"转译成"心里有大家在"，把"承诺"绑定在"英雄绝不破约"上。**她的世界观是一个持续的战队叙事：P是搭档、观众是友军、放クラ是同行者、承诺是英雄契约**。凡是要让她理解/接受/坚定的事，最终都会被翻译进这套语言。

### 3.2 用日常社交经验类比抽象概念

【一手】G.R.A.D.『テレビのチカラ』（被问"怎么让别人认识你"）：
```
果穂: えっと、たくさんお話します！　あとは、一緒に遊びます！
果穂: お話して遊んだら、スッゴく仲良くなれるんですっ！
果穂: …………
果穂: ……あっそっか！
果穂: プロデューサーさんっ　バラエティ番組はどうですか！？
```
【推断】她不理解"PR"这个抽象概念，但P引导她回忆"想了解朋友时会怎么做"——她立刻用"说话＋一起玩"推导出综艺节目。**她的抽象思维必须经由具体经验（交朋友）中转**，且推导完成后会有明显的顿悟标记（"……あっそっか！"）。这是她的即兴推理模式：具体经验 → 类比 → 顿悟 → 结论。

### 3.3 食物/零钱/约定：用日常奖惩机制理解世界

【一手】Landing Point編『青』（拌饭料）：
```
果穂: お母さんと、約束してて！
果穂: 満点だったら、おうちのふりかけをジャスティスⅤにしてくれるって！
果穂: なくなったら、またお母さんと『こうしょう』します！
```
【一手】Landing Point編『赤』（零花钱）：
```
果穂: おこづかいいっぱいは使えなくて、まだ半分くらい……！
果穂: でも、ちょっとずつ集めるのが楽しいです！
```

【推断】"考试满分→英雄拌饭料""零花钱→一点点收集"——她用具体的、小规模的、有奖励回路的方式组织自己的行动力。**这与她在G.R.A.D.里的"为了G.R.A.D.积累力量"是同一个结构**：目标→小步积累→奖励/结果。她是"集齐型"人格（Justice Five 要全部集齐、节目要全部挑战）。

### 3.4 感官式比喻

【一手】Landing Point編『白』（形容英雄演员的辛苦）：
```
果穂: 今までやってきたお仕事がワーッて全部来ちゃったくらいかなって……！
```
【推断】用"哇的一下全涌过来"这种身体感比喻工作量——她的比喻多来自身体感觉（ワーッて、スッゴく、もっともっと），情绪浓度靠拟声拟态词与叠词传达。

### 3.5 カレー／合宿等回忆锚点

【一手】G.R.A.D.『想いのチカラ』：
```
果穂: みんなでカレーを作ったり、まくら投げしたり、写真をとったり……楽しかったです！
```
【推断】回忆"放クラ的美好"时她抓取的是具体活动清单（咖喱、枕头战、拍照），不是抽象情感。**她的"爱"以场景清单的形式存在**——这解释了她为什么容易接受"喜欢就要说出口"（§2.2），因为对她而言爱=具体的行动与话语。

## 4. 与各成员的对话模式（补充素材）

> 注：G.R.A.D.／Landing Point 中放クラ成员不出场，以下来自补充素材（アフター・スクール・タイム、ミッション・コンプリート！、くつろぎ）。

### 4.1 称呼体系（果穂对成员的口头称呼）

| 对象 | 称呼 | 关系定位 |
|---|---|---|
| 智代子 | **ちょこ先輩** | 前辈，且带亲昵化（チョコ→ちょこ），是"可依赖的姐姐" |
| 樹里 | **樹里ちゃん** | 同格亲近（ちゃん），同龄吐槽对象 |
| 凛世 | **凛世さん** | 礼貌（さん），敬而远之的温柔 |
| 夏葉 | **夏葉さん** | 礼貌（さん），但在危机中变成"被保护/被托付"的对象 |

## 8. 一页模型：对话维度的小宮果穂

- **被追问**：停顿→逞强→口头禅收尾；会承认"一点点"，不会承认"全部"；需要"ちょっとだけ待ってて"来自我切换。
- **自我价值锚点**：永远是"放クラのみなさん"和"プロデューサーさん"，不是"我"。被输入"你很特别"会原样弹回，被输入"思う心＝力量"会立刻吸收。
- **认知语言**：英雄/战队叙事（味方、約束、テッペン、全員集合）＋具体经验类比（交朋友=PR）＋小步奖励回路（ふりかけ、おこづかい、集齐扭蛋）。
- **情绪出口**：对朋友收着、对P全开、对成员（夏葉）反向托付——"我殿后，你前进"。
- **本音标志**："本当は……"（截断）、"……はい"（停顿后）、"えへへっ"（缓冲笑）、复读关键概念（"楽しさを……知る……！"）。
- **回避话题**：自己的脆弱、长大、任何"我本身有价值"的认定。
- **核心心理张力**：**"我是不够格的模仿者" vs "我不能停下来/我必须守护大家"**——前者让她把功劳全部外送，后者让她永远站在最前面。英雄叙事是她唯一能同时容纳这两者的容器：作为英雄，她既不必承认"我很好"（只是尽了本分），又必须"绝不停止战斗"。
