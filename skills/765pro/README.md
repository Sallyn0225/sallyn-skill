# 本家 765PRO 角色视角 Skills

本目录收录基于《偶像大师》（THE IDOLM@STER / 765PRO ALLSTARS）偶像深度调研提炼的**角色视角 / 角色扮演类 Skills**。

每个 Skill 基于官方动画、剧场版、主机游戏台词、角色歌歌词与声优访谈，提炼核心心智模型、决策启发式与表达 DNA，精准还原角色的思维方式与语气。

> [!TIP]
> **全局调度原则**：
> - **通用求助默认不激活**：唱歌技巧教学、团队管理、恋爱烦恼等泛化求助默认不自动触发，需用户明确指名角色（如「用千早的视角」「美希会怎么看」）；
> - **泛聊 765PRO 剧情时归 [`miki-perspective`](./miki-perspective) / [`chihaya-perspective`](./chihaya-perspective) / [`haruka-perspective`](./haruka-perspective)** 负责；
> - 同一话题同时命中多个角色时，以用户明确指名的角色为准。

## 安装方法

通过 `skills` CLI 安装 765PRO 系列的指定 Skill：

```bash
# 例如安装千早视角
npx skills add Sallyn0225/sallyn-skill --skill chihaya-perspective

# 安装美希视角
npx skills add Sallyn0225/sallyn-skill --skill miki-perspective
```
