### 1.1 W.I.N.G.編（开服主线，2018）：「被拉着走的人，学着一个人站」

剧情文件（repo路径 `data/story/大崎甜花/W.I.N.G.編/`）按事件ID排列：

1. **「眠る可能性」（面试/P初遇）**【原文】
   - 成为偶像的理由（第一原点）：**「なーちゃんが、一緒にアイドルになろうって……言ってくれたから……です……」（因为小奈说想和甜花一起当偶像）**。P问「为什么想当偶像」，她的回答里没有自己，只有妹妹。
   - 「甜花……あんまり、他の人と話さないから……」——面试时连对话都无法顺利进行。
   - 决定合格瞬间她的反应：「甜花が……アイドル……？」——不敢相信被选上的是自己。
   - 咬舌台词初出：「甜花……頑張りましゅ！」（会加油哒！）
   - P的内心评价：「妹さんのことを話すときの笑顔……この笑顔を見てるとこっちまで楽しくなってくるな」——谈妹妹时的笑容是她最初展露的魅力。
   - ※本篇标题即「沉睡的可能性」：P看中的是尚未成形的可能性，而不是现状。

   - P提出让她尝试**solo工作**建立自信——WING篇的核心机制（让她离开甘奈的羽翼）。

3. **「だけど、それでも」（中盘挫折）**

4. **「誰でもない甜花を」（后段转折）**

### 1.2 G.R.A.D.編（2019）：「I~」六连问——从Idle到Identity

六话标题全部以「I」开头，构成语义链（事件ID顺序）：**I do → Idle → Ideally → Id → Ideal → Identity**。

1. **I do**：接到偶像祭（フェス）个人offer。「また……ひとり……」的恐惧→P背书「甜花ならきっと上手くやれる」→她的依赖逻辑原样暴露【原文】：**「プロデューサーさんが……見てて、くれるなら……大丈夫、だから……！」**（只要制作人看着我就没问题。）
2. **Idle**（谐音Idle=怠惰）：合同练习跟不上，摔跤，作业堆积。但关键在结尾【原文】：**「だから……甜花、大丈夫……絶対……大丈夫、だから……何が、あっても……全部、全部……大丈夫に……してくれる、から……」**（大家都支援我，所以无论发生什么，都会**替我**变得没问题。）——把「变没问题」的主语完全交给了他人。P的沉默（「………………」）即本篇危机伏笔。
3. **Ideally**：现实打击——工作人员直接指出她严重落后，同场偶像背后说「早く、諦めてほしいよね」（希望她早点放弃）。她求P：「プロデューサーさん、なら……どうにかしてくれる……よね……？」P给出全篇最关键的回答【原文】：**「甜花が、どうすればいいか……それは、甜花が自分で考えないといけない」**（该怎么做，必须甜花自己想。）她崩溃：「自分でって……どうやって…………？」
4. **Id**（本篇最高潮，系列著名场面）：深夜事务所，被临时告知可能取消出场资格。P不再给答案，而是问出核心问题——**「甜花は、何がしたい？」**（甜花想做什么？）
   - 她的第一反应：「甜花、したいこと……なんて……だって……甜花、なんもできない……」（什么都不会的人，不配有想做的事。）
   - P三个选项逐一拆解：「何ができるか、何をしなきゃいけないかじゃなくて——何をしたいか、なんだ」（不是能做什么、该做什么，而是想做什么。）以及承诺：「もしも甜花が本当に逃げたいって言うなら、甜花がちゃんと逃げられるように、サポートする」——**意志优先，连逃跑的自由都给她**。
   - 长时间沉默后的回答（全篇最重要台词）【原文】：**「諦めたくない」**（我不想放弃。）
5. **Ideal**：偶像祭当日。位置被降到后排第二列最左端（「モニターに抜かれることはほとんどない……もしかしたら、いなくても誰も気付かなかったかもしれない」）。但她自主申请加练，坚持到最后。结算【原文】：**「……最後まで、できた……諦めないで……できた……！」「甜花……頑張った……！」**——第一次以**自己的力**为基准评价自己（P：「諦めずに、自分の力で、よく頑張ったな」）。
6. **Identity**：日常回归。放学后想去游戏厅——「新作の、アーケード……やりたいの……入ってるから……」；主动邀请P：「プロデューサーさんも……頑張ってるから……」（P也很努力了，所以想一起玩）→「頑張ってる甜花と、頑張ってる俺へのご褒美の日だ！」；车内补觉前宣言【原文】：**「……いい、遊びの……ために……充電、開始……」**（为好好玩耍，开始充电=睡觉。）——「游玩=奖励」是她可持续努力的燃料。

> G.R.A.D.篇弧线总结【推断】：从「Idle（怠惰/被供养）」经「Id（自我拷问）」到「Ideal（以自己的标准完成）」与「Identity（把游戏与奖励纳入自我）」——甜花的身份问题不是「我是谁」的抽象命题，而是「我的意志是否存在」的实证命题，答案=「諦めたくない」。

### 1.3 S.T.E.P.編（2022/12实装）：前史补完——「周回遅れ」的人生与约定的真相

六话（ID顺序）：**旧・甜花の完璧な一日 → 周回遅れ → 約束？ → なーちゃんはアイドル、甜花も → 明日から頑張るから → ベターな日々は続く**。

1. **旧・甜花の完璧な一日**（偶像出道前的日常）【原文】：
   - 「起きる、食べる、ゲーム、寝る」「食べる、ゲーム、寝る」「これが、甜花の完璧な一日」——起床吃饭打游戏睡觉=**完美的每一天**（无反讽，真诚宣言）。
   - 甘奈做好早饭兼午饭、出门前邀她「たまには一緒にお出かけ……しない？」→「今度、ね……」（下次吧）→「約束だよ～？」——**「下次吧」的敷衍之约成为后续一切的发端**。
2. **周回遅れ**（落后一圈的人生）：考试赤点、体育课全班唯一「周回遅れ」、升学志愿调查表写不出来。甜花的恢复机制自述【原文】：**「落ち込むこと、いっぱいあるけど、お休みの日、あれば回復」**（令人消沉的事很多，但只要有休息日就能回复——游戏式HP管理思维。）而甘奈已在两所第一志愿之间纠结——妹妹有复数的梦想，姐姐一个都没有（「まだ、何も…………」）。
3. **約束？**：作业又是甘奈代写（「課題、なーちゃんに……ほとんど、やってもらっちゃった」）。甜花决心「甜花も、何か……なーちゃんに、やってあげよ……！」——翻找自己唯一能做的事时想起「一起出门的约定」。此时甘奈再次邀约「これ……一緒に行かない……？」，甜花答应——甘奈揭底【原文】：**「──アイドルのオーディションっ！」**。**「一起出门」的约定，目的地就是偶像面试。**
4. **なーちゃんはアイドル、甜花も**：面试当日视点重演（与WING初遇同场景的另一侧写）。她的内心：（ゲームの、アイドルは……綺麗な服着て、歌って踊ってた……じゃあ……甜花も……？）（……でも……なーちゃんなら、絶対、似合う……）——**先想到妹妹绝对合适，再怀疑自己**。练习中跟不上，trainer吼「諦めない、体動かす！！」。收尾：「アイドル、なるの……大変、だね…………甜花には……────」。
5. **明日から頑張るから**：装肚子疼请假在家（「お休みは……大事……！」），看到甘奈留的饭与短信而愧疚。核心恐惧浮出【原文】：**「（なーちゃんが……すごいアイドル、なって……でも、甜花は……だめだめで……そしたら、もう甜花は……なーちゃんと、一緒にいられない……？）」**——**害怕被甩下、无法再和妹妹在一起**，是她努力的真实初动力。电话里对P：「頑張ったら……なーちゃんと、一緒に歌ったり……踊っても……大丈夫に、なれる……？」→「甜花、明日から……頑張りましゅっ……！」——**「明天开始努力」**（她的标志性拖延句式，但此处第一次用于真正的决心）。
6. **ベターな日々は続く**（STEP最终话，给P的回信）——甜花自我定义的全文【原文】：
   - 过去的甜花：「起きて、食べて、ゲームして、寝る。なーちゃんがいて、パパとママがいる。**それが それだけが、甜花だった時のことです**」
   - 现在的甜花：「起きて、食べて、レッスンして、お仕事して、ゲームもして、寝る。なーちゃんがいて、パパとママがいて、千雪さんがいて プロデューサーさんがいる。**それが、今の甜花です**」
   - 结论句：**「今の甜花は 前の甜花よりもいい。だから、これから先はもっといいよね？」**（现在的甜花比以前的甜花更好。所以今后会更好，对吧？）——**以「比昨天好一点」为满足的增量幸福观**（ベター=better，不求ベスト）。P.S.还讨要生日礼物：「お誕生日のプレゼントも、待ってます」。
   - 细节：信纸选了**デビ太郎**（她的恶魔系吉祥物）图案；甘奈纠结商务风信纸——双子品味反差。

### 1.4 Landing Point編（2023/12实装，5周年）：「頑張れ」的和解——从被动发光到主动应援

六话标题为接龙链：**もう頑張ってる → だから ちょっと → ちょっと 思ってた → 思ってた けどね → けどね そうだったんだ → 頑張れ、頑張れ！**。主线为甜花的**首次one-man live**（单独演唱会）+广播节目「グッド・ネムレナイト」复活。

1. **もう頑張ってる**（她的口头禅首次作为标题）：为one-man live锻炼体力，P习惯性打气「甜花ならまだまだ頑張れるはずだ」，她低声反驳【原文】：**「……甜花……もう、頑張ってる……」**。但本话结尾她自己重燃：「甜花……営業再開、でしゅ……！——です……！」（营业再开，哒——的！）※「闭店/营业」=她用店铺隐喻描述自己的精力开关。
2. **だから ちょっと**：跑步10分钟不停（自我感动：「甜花、頑張ってる……！」）后立刻想午睡。遇到练习自行车的女孩子——**是想赶在妹妹之前学会骑车的姐姐**。甜花想说「頑張——」又咽回去：「……甜花……もう、頑張ってる……」；女孩却说：「『頑張れ』って言ってくれるの、嬉しい！ひとりだと やっぱもうやめようかなって思っちゃうもん」。
3. **ちょっと 思ってた**：广播复活特别版，来信大量是「想被甜花应援」。她的播音稿自白【原文】：**「お便り、読んでるだけでも……みんな……すごく、頑張ってるって、思う……だから 甜花は、これ以上『頑張れ』って、言えない……」**——认为对已在努力的人说「加油」是失礼/是自上而下，这成为她的心结。
4. **思ってた   けどね**：独自自主练习。P想发「がんば——」却在输入法前停手（「……わかってるからこそ 頑張る甜花を心から応援したいと思ってるのに」）。甜花收到甘奈（「ひとりレッスン、さみしくない、よ──」）与千雪（「甜花も、３人で、あわせるの、楽しみ──」）的回复，自己搜索节目tag看到听众感想，重新开始练新歌振付。
5. **けどね そうだったんだ**（LP篇文眼）：再次遇到自行车女孩——她已学会不摔倒：「前に、お姉ちゃんが『頑張れ』って言ってくれたから、頑張れたの！」甜花的顿悟全文【原文】：**「『頑張れ』……そう……だったんだね。プロデューサーさんも ファンのみんなも、なーちゃんも、千雪さんも……甜花の、背中……押してくれてたのは──『頑張れ』……！」**——原来推着她走到这里的，正是「頑張れ」这个词。随即当场应用：（やっぱ……休憩……なし……！）（甜花も……もうちょっと、走ろう……！）并向P提出：**「甜花のこと、応援してくれる人たちに……ライブで、応援の気持ち……伝えられる、かな……？」**（想在live上把应援的心情回传给应援她的人。）
6. **頑張れ、頑張れ！**（最终话）：one-man live成功（「お客さん……嬉しそうだったり、泣いてくれてたりしてて……その景色は、すっごく……覚えてる」）。结尾完成闭环【原文】：**「プロデューサーさんが、頑張ってるって 知ってるけど……言うね。——頑張れ、プロデューサーさん……！」**——明知对方已在努力，仍然要说「加油」；P回「頑張れ、甜花！」，两人齐声「頑張れ、頑張れ──」。
   > LP弧线【推断】：「もう頑張ってる」（拒绝被动打气）→理解「頑張れ」是曾经的自己被托住的手→「頑張れ、頑張れ！」（主动向他人输出应援）。她从应援的接受者毕业为应援的给予者——LP即「Landing Point」（着陆点）：依赖与被依赖的双向性终于被她本人理解。

- **口癖/发声**：「にへへ」（标志性笑，数十处）、「あうぅ……」「ひゃっ！」（受惊）、「～でしゅ……！」（紧张/撒娇时把「です」说成「でしゅ」，如「営業再開、でしゅ」「頑張りましゅ」）。
- **断续语体**：句中大量省略号与倒装补正（「えと……えっと……」「──です……！」），紧张时语序破碎；对P以外的人几乎不开口（初期）。
- **游戏词汇迁移**：周回遅れ／クリア／ステージ（考试）／装備・防御力アップ／充電／閉店・営業再開／（見えてきた）「無敵」。
- **安静的梦想口吻**：谈到愿望时句尾上扬确认（「～かな……？」「～だよね……？」），把判断权递给对方——与她把自我托付关系的结构同构【推断】。

### 5.1 唯一原创solo曲「また明日」（2021）【歌词】

- 作詞：鈴木静那／作曲・編曲：JUVENILE／歌：大崎甜花（CV.前川涼子）
- **GAME初出**：シャイニーカラーズ（2021/01/12，游戏内）【二手：music765plus乐曲DB】
- **CD初出**：THE IDOLM@STER SHINY COLORS COLORFUL FE@THERS **-Luna-**（2021/02/17，LACA-15862，Tr.4）【官方：lantis官网】——甜花所属的是「Luna（月）」组，与WING篇「お月様、きらり／月はやがて輝いて」的月意象一脉相承。
- 2024年起作为シャニソン（Song for Prism）「THE FIRST TENKA」项目曲配信多版MV（官方MV/縦MV/デビリッシュフューチャー衣装版等）。
- 歌词全文（utagenet转载，JASRC许可页）核心句：
  > 「一歩一歩 ゆっくりと前を向いて 歩いてゆこう／お月様が顔を出せば また明日」
  > 「寄り道したあの日見つけた場所 ひだまりに咲いている花／太陽が友達 懐かしい匂いの 気どらない街」
  > 「明日も晴れるかな 今日と同じように」
  > **「小さくて 平凡で頼りなくたって 夢を見ると言うことが大事」**
- 解读【推断】：
  - 「一步一歩、ゆっくり」＝她的低速成长哲学（与G.R.A.D.「甜花は甜花のスピードで成長してる」同构）；
  - 「お月様が顔を出せば また明日」＝**把「また明日（明天见）」从拖延话术改写为温柔约定**——STEP篇的「明日から頑張るから」在此被歌曲正名为：明天不是逃避的场所，是继续的承诺；
  - 「小さくて平凡で頼りなくたって 夢を見ると言うことが大事」＝**自我信条的最凝练表达**：渺小、平凡、不可靠也没关系，重要的是开口说「我有梦想」——正是对「特技：没有什么特长」的档案与「諦めたくない」的GRAD回答的歌词化。
  - 月亮意象：她自己的星（双子座的姐星）不亮，但月亮是「借太阳光发亮的天体」——甜花的偶像论（借大家的光发亮，再照亮别人）【推断，注意：歌中并无此明示，属意象延伸】。
