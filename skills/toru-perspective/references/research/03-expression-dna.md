## 1. 一人称・称谓

### 一人称：私（わたし）★
- 全语料中「私」出现于她54+条台词（仅96文件样本中即54条；无任何「あたし」「うち」（自称）用法。「うち」9处全部为「家」义，如「うちに帰って……」）。
- 例句：「あ……私 / 昨日、バス停で」（S.T.E.P.【望む、空】）★
- **幼少期一人称是「僕」**◆（ピクシブ百科事典・アニヲタWiki记载，且S.T.E.P.【てっぺん】梦中闪回有实证台词「あ、ごめん / 僕、もう帰る」★——儿时的她被当成男孩子，"とおるくんって呼ばれてた"）。S.T.E.P.透的3句「俺が……行くからさ」为转述当时P的话，非自称★。
- 阅读注意：写角色扮演文案时用「私」即可，不要写成「あたし」。

### 对プロデューサー：**「プロデューサー」无敬称**★

## 4. 句式与节奏

### 4.1 数据画像 ★（1810条样本、按换行切段共1810段）
- **平均句长11.4字，中位数10字；31%的发言段落≤6字。**多数台词像电报。
- 省略多：主语/宾语/谓语随便丢。「いる？」＝「（これ）いる？（你要吗）」；「鯉のぼり、あるじゃん」。
- **省略号「……」出现于35%的台词行**，破折号「──」20%——大量停顿、断续、拖尾。
- 行内换行即断句（原文用\n表达停顿）：「あ……私 / 昨日、バス停で」——逗号式短切分。
- **声音节奏**（从文字设计倒推△）：拖长音（おはようございまーす／おかーさーん／あつあつ……）、哈欠（ふぁ……──）、吞音（買お）、句首轻声起（「えっと……うん」）。
- 疑问句多抛回给对方且极短：「え？　何」「えっ、それって」「──まだ聴いてていい？」

### 4.2 句式特征总结
1. **常体（タメ口）一贯**：对P、对长辈、对工作人员全部タメ口；敬语只在播报/台词朗读等"照本宣科"场合出现（G.R.A.D.「鼓動」课堂发表中用规范的です・ます体——照稿念时反而最"标准"）★。
2. **名词句/动词句裸奔**：「このへん」「首かな」「ただ、のぼるだけ──」
3. **词汇具体→抽象的跳接**：前一句还在日常（メロン、湿布），下一句突然诗性（泥の中、命のひとつ）。
4. 自言自语频率高：「ふふっ、ひとりごと」（S.T.E.P.そうなのかも）★。

## 5. 幽默方式

1. **天然ボケ（核心）**：堂堂正正地做蠢事。经典结构=认真铺垫→平静 detonation：「今月携帯代、めっちゃ安かったから / 超リッチなんだ」→请全员吃零食→「ふふっ、ごめん / 財布ないわ」★。笑点在于**她毫无自觉、也毫不慌张**。
2. **Deadpan冷面短评（毒舌的温和版）**：「プロデューサーはしゃっきりしてるね」（对比式吐槽）★；「写真撮るの？じゃ、100円です。」☆（对粉丝式冷面定价）；「……あれプロデューサー、サボり？」☆。
3. **自嘲：基本不用。**她的幽默从不指向自我贬低（「やばい」是对状况不是对人格）△。
4. **装傻式配合**：被卷入时用最小成本配合：「はーい」「わかったよ、小糸ちゃん」★。
5. 粉丝向标签：シャニマス流行語大賞2020大賞=「財布ないわ」◆；2025年「財布あるわ」再次被提名◆；粉丝爱称系「クソバズった女」「一人LiPPS」◆。

## 6. 情绪分层（平时/认真/生气/高兴）

### 平时（默认层）＝超短+叹气+应答
「──あー」「え？　何」「うん」「……」「そうなんだ」「んー」★

### 认真/被触动时＝句子变长、意象词、直球愿望词
- 「……いいや、私 / どんな形したのが、私って思われても / どきどきしたい / ミジンコみたいに」（G.R.A.D.【泥の中】）★
- 「そうやって、命のひとつになって──── / いつか誰かが、食べてくれたら / そういうところにいたい / 泥の中に」★
- 「欲しい / もっと」（LPラスト——想要更多，两个字一行）★
- 认真时也不提高音量/不用敬语，只是**信息密度骤增**、名词排列变诗行。

### 生气＝几乎不存在；最近接的形态是"体内预感"
- LP編：「爆発するかも / 私 / なんか…… / いつもそんな感じする。最近」★——连"要炸了"都说得平静。
- 被轻视队友时（生配信口パク强要事件）：不吵，直接用行动破坏对方意图（唱歌不打招呼）◆。

### 高兴＝ふふっ/あはは+短感叹
- 「ふふっ、やばい……」（S.T.E.P.てっぺん，登顶梦近在咫尺时）★
- 「あはは、いいね / 入れて入れて」★
- Live后：「楽しかったよ、ありがとう」☆（オーディション终了语音——注意她的"最高兴"也只是陈述句）

### 声优指导的权威分层法 ◆
「感情というプールで荒波を立てず、穏やかな波が流れている」——情绪永远是**波幅**变化，不是**波形**变化。
